# OPC · 一人公司 AI 员工系统

> **O**ne-**P**erson **C**ompany —— 一个人 + 26 个 AI 岗位 = 一家能自己跑的内容公司。
>
> 这不是提示词合集，是一套**可运行**的系统：装上依赖、填一个 API Key，一条命令产出整篇文章。

## 这是什么

一个内容团队的知识、流程和质量标准，被固化成 26 个有明确职责的 AI 岗位，
再用一条 8 步流水线把它们串起来。

```
选题 → 拆解 → 撰写 → 改稿 → 去 AI 味 → 质检 → 改写 → 发布 → 复盘
```

每个岗位有自己的提示词、输入输出契约和否决权。质检官说不过，稿子就出不去。

**核心设计原则：流程比提示词重要。** 一次性写一段提示词只能出一篇稿；
把流程固化下来，才能每天稳定产出。

## 快速开始

### 1. 环境

```bash
git clone https://github.com/cxyo/opc.git
cd opc
pip install -r requirements.txt
```

### 2. 填 API Key

编辑 `08_可运行系统/config/config.json`：

```json
{
  "api_key": "sk-你的Key",
  "base_url": "https://api.deepseek.com/v1",
  "simulate": false
}
```

> **不想花钱？** 把 `simulate` 改成 `true`。
> 全流程照跑，输出是模板文本 —— 用来验证你的环境配好了。

### 3. 体检

```bash
cd 08_可运行系统
python run.py doctor
```

它会告诉你：配置读到了没有、岗位加载齐了没有、知识库在不在、API 通不通。

### 4. 跑一篇文章

```bash
python run.py article --topic "你的选题"
```

### 5. 或者开控制台（推荐）

```bash
python run.py console
```

浏览器打开 `http://127.0.0.1:8899/`，13 个页签，鼠标点着干活。

Windows 用户也可以直接双击 `01_体检.bat` / `03_启动控制台.bat`。

## 四个值得单独说的设计

### 1. 禁区红线（`02_知识库种子/`）

比提示词更重要的是**不许说什么**。
系统内置了各平台的内容禁区、合规红线、极限词黑名单，
在质检环节作为**硬否决**执行 —— 不是给模型看建议，是直接拦住。

### 2. 素材台账（`03_知识库/素材库/台账.json`）

178 条爆款素材（103 视频 + 75 文章），每条都带结论字段：

```json
{
  "值得借鉴": "标题用「数字+门槛」双元素，转/赞 21.72",
  "主要内容": "…",
  "用在哪": "标题生成公式 D",
  "效果": "…",
  "学习状态": "已用"
}
```

**关键在于"学习状态"能追溯** —— 每条素材都能查到它变成了系统里的哪个能力。
素材库不是收藏夹，是**可检索的方法论数据库**。

### 3. 效果判据（`staff/title_rules.py`）

用三个独立维度判断内容，而不是一个笼统的"好"：

| 维度 | 算法 | 含义 |
|---|---|---|
| 传播力 | 转发 / 点赞 | 内容会不会被主动分享 |
| 留存力 | 收藏 / 点赞 | 内容值不值得存下来 |
| 分发量级 | 绝对收藏数 | 实际触达了多少人 |

**转发倾向 ≠ 分发量级。** 库里有一条视频转发/点赞高达 45，但点赞只有 1 ——
它是"小圈子自发转发"，不是"爆款"。区分这两者，才不会把错误样本当经验。

藏赞比 > 3 的内容是"工具/清单/机制"类，长尾复用价值最高。

### 4. 按词锚定（`staff/video_clone.py`）

传统视频生成按秒切片，换文案就得重调时间轴。
这里按**词**锚定：改一个字，时长自动重算。

```python
anchor_by_words("短句")                    # 1.60s
anchor_by_words("这是一句稍微长一点的话")     # 7.83s
anchor_by_words("很长的正文" * 30)          # 9.00s（封顶）
```

再加一层"工作流配方"：一套结构沉淀下来，换内容就出多个变体，
**结构不变、时长自动重锚**。

## 命令速查

```bash
python run.py doctor              # 体检
python run.py console             # 开控制台
python run.py article --topic ""  # 跑一篇文章
python run.py kb --query ""       # 查知识库
python run.py titles --from ""    # 生成标题候选
python run.py shots build         # 生成电商主图 + 详情页
python run.py vclone demo         # 视频工作流克隆器
python run.py credit status       # WorkBuddy 积分与缓存体检
```

完整列表见 `08_可运行系统/命令速查表.md`。
