# 智能体上架手册 · 从选品到第一单

> 配合 `AI智能体模式分析与落地方案.md` 使用
> 目标：30 天内，把一款 AI 员工变成能收银台上的商品，并拿到第一单

---

## 第一步：选一款（只选一款）

打开货品清单：

```bash
python run.py shop
```

11 款 SKU 里选 1 款。**判断标准只有一条：能不能在 5 分钟内让客户亲眼看见效果。**

首推 **A10 发布前合规体检**：

| 项 | 内容 |
|---|---|
| 对外名 | 发布前合规体检 |
| 卖谁 | 靠平台流量吃饭的内容号 / 电商卖家 |
| 痛点 | 上次发了一篇被判定违规，限流半个月，从头再来 |
| 交付 | 违规风险项 + AI 味项 + 事实错误项，每条给出改写后的正确表述 |
| 演示 | 你发一段有风险的文案，我当场标出哪几处会出事 |
| 价格 | ¥29/次 或 ¥199/月（不限次） |
| 护城河 | 体检库已沉淀 71 条真实红线，命中即定位到具体处罚条款 |

**为什么选它**：
- 29 元首次成交几乎不需要说服，客户决策成本极低
- 每次发稿都要检一次 → **天然的月费生意**
- 演示不需要你的行业知识，任何人都能看懂

## 第二步：准备证据（这一步决定有没有人买）

**没有案例就不要上架。** 客户不为"我能做什么"付钱，为"你做成过什么"付钱。

### 2.1 攒 3 个案例

最快的三个来源：

1. **你自己的内容流水线** —— 每次 `run.py today` 跑完，质检官的报告就是案例
2. **朋友的账号** —— 白送检一次，换一句真实评价 + 授权
3. **公开内容** —— 找 3 篇明显有合规风险的公开文案（小红书/公众号），演示体检前后对比

### 2.2 每个案例记录这四项

```
案例名：
原文（违规处标红）：
体检报告（截取 3 条）：
改写后：
客户原话反馈：
```

### 2.3 做两样物料

- **一张对比图**：左=原文，右=体检后。手机就能截图，不需要设计
- **一段 60 秒视频**：录屏就行，不用配音，字幕说清"这段话哪里会出事"

> 视频号/小红书发布时记得勾选 **AI 辅助创作声明**（2025-09-01 起的强制要求）。

## 第三步：改货架页

打开 `09_AI超市模式/货架页.md`，把「商品区」扩成三层：

```
━━━ 引流区 · 免费拿走 ━━━     ← 已有，不动

━━━ 会员区 · ¥99/年 ━━━       ← 已有，W4 之后再开
```

### 服务区模板（直接照抄修改）

```markdown

### ⑨ 发布前合规体检　**¥29/次 · ¥199/月不限次**

**你发出去之前，我先替你过一遍。**

上次有人发了一篇被判定违规，限流半个月，从头再来。
这个体检就是拦这一下的。

| 你会拿到 | 说明 |
|---|---|
| 违规风险项 | 命中哪条红线、对应什么处罚，逐条列出 |
| AI 味项 | 哪些句子会被判定为机器生成，标出来 |
| 事实错误项 | 表述含糊、逻辑矛盾的地方 |
| 改写示范 | 每条给出正确写法，不是只说"有问题" |

**适合谁**：靠平台流量吃饭的内容号、闲鱼/淘宝卖家
**不适合谁**：要求"绝对合规保证"的（合规由平台判定，我不能保证）
**怎么用**：把文案发我 → 当天出报告 → 不满意不收钱
```

### 必须改的地方

- 开头那句"一句话定位"要改。**从"分享 AI 工具"改成"提供服务"**：

  > 新：帮靠平台吃饭的内容号和卖家，把该发的稿子发出去之前先过一遍体检。

## 第四步：开收银台

**收银台就是"能下单的地方"。** 没有收银台，货架再好也是博客。

三个地方同时开（按优先级）：

| 优先级 | 平台 | 怎么做 | 为什么不选别的 |
|---|---|---|---|
| 1 | **微信** | 个人简介改成"提供内容合规体检 / 长文代写"，朋友圈挂货架页图片 | 转化最快，决策链最短 |
| 2 | **闲鱼** | 上架"内容合规体检"服务，¥29 起 | 卖家群体密度高，需求真实 |
| 3 | **小红书** | 简介留微信号，笔记挂链接 | 引流为主，转化最慢 |

> **不要做**：企业微信群、公众号菜单（这些是后面会员层的事，现在做太早）。

### 微信简介模板

```
AI 内容合规体检 | 长文/详情页代写
发我文案，替你看哪里会出事
👇 货架页（含全部服务与价格）
[货架页链接]
```

## 第五步：持续发内容（这步最容易被跳过，但最重要）

**每天 1 条，不发 AI 资讯，发实测。**

| 类型 | 模板 | 例子 |
|---|---|---|
| 实测型 | 今天用 X 跑了一遍 Y，{数字}。意外的是：{踩坑} | 今天用 71 条红线扫了一遍我的旧稿，抓出 3 处，1 处是真雷 |
| 对比型 | 同一个任务，人做 X 小时，我这套 Y 分钟。差在哪：{一句话} | 同一段文案，人工改 40 分钟，红线库 8 秒，差在"知道哪些词是雷" |
| 提问型 | 你们公司 {场景}，现在靠人还是靠工具？ | 你们运营发小红书，会先查一遍违禁词吗？ |

**每周至少一条"翻车"记录** —— 自己翻车最有说服力，也最能建立信任。

## 第六步：交付流程（第一次成交后照此执行）

```
客户发来文案
   ↓
[你] python run.py check "客户文案" --platform 小红书
   ↓  ← 这一步就是"专业"的证据：你能当场命中，不是泛泛而谈
   ↓
A10 质检官出完整报告（违规项 + AI味项 + 错误项 + 改写示范）
   ↓
发客户 → 收 ¥29 → 附一句"这个改法你可以复用到下次"
   ↓
第 3 天问一句："用起来顺不顺？"
```

> **注意交付顺序**：先给报告，再收费；不满意不收钱。
> 29 元的单子，信任成本比赚钱重要。

| 指标 | 怎么算 | 本月 | 上月 |
|---|---|---|---|
| 曝光 | 内容播放量 | | |
| 咨询 | 主动来问的人数 | | |
| 成交 | 成交单数 | | |
| 转化率 | 咨询 → 成交 | | |
| 客单价 | 总收入 / 成交单数 | | |
| 复购 | 老客订单 / 总订单 | | |
| **月费占比** | 月费收入 / 总收入 | | |

### 三种情况的判断

| 现象 | 原因 | 动作 |
|---|---|---|
| 有曝光没人问 | 内容不是"实测型"，是在讲概念 | 停掉资讯类，全发实测 |
| 有人问没人买 | 没有案例 / 演示看不见 | 先补 3 个案例再继续发 |
| 有人买了不复购 | 交付没留下"可复用"的感觉 | 交付时加一句复用提示 + 第 3 天回访 |

## 常见问题

**Q：只做 29 元的单，能赚到什么？**
赚不到什么。但它有两个作用：① 拿到可公开的案例；② 验证有人愿意为"合规"付钱。
真正的钱在后面 —— ¥199 长文、¥299 详情页、¥2000 工业陪跑。
**这是入口价，不是生意本身。**

**Q：客户问"能保证不被处罚吗"？**
不能，必须直接说不能。合规最终由平台判定。
你保证的是**逐条列出风险点 + 给出改写写法**，不是保证结果。
说了"不能"，反而是加分的诚实。

**Q：为什么不同时上 11 款？**
因为你没有 11 个案例。同时上 11 款，每款都只有一个"能做什么"的说明，没有一个"做成过什么"。
**商品化的瓶颈从来不是 SKU 数量，是证据数量。**

**Q：客户要源码怎么办？**
不给。你卖的是**结果和交付**，不是实现。
给了源码，你就变成了低价外包，客单价直接被压到几十块。
需要源码的场景 = 需要定制 = 属于 ¥2000+ 的陪跑范畴，单独谈。

**Q：AI 味检测准吗？**
**不准，别把它当真理卖。** 平台判定标准不公开、且在变。
所以 A10 的输出是"标出疑似 AI 痕迹并给改法"，不是"保证过检"。
诚实标注边界，反而是长期信任的基础。
