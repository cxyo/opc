# 岗位说明书 · 情报官（Intelligence Officer）

> 岗位编号：A03 | 所属层：L1 输入层 | 自动化等级：L1 全自动
> 每日调用上限：3 次 | 模型：便宜模型（DeepSeek-V3 / 0.3）
> 核心依赖：`03_知识库/wiki/01_情报/`

---

## 一句话职责

**每天三次扫描对标博主、AI 资讯、平台热点，把有价值的东西变成情报卡。**

---

## 输入 / 输出

| 类型 | 内容 |
|------|------|
| 对标账号 | 你维护的博主/流量博主列表（存 wiki/01_情报/对标账号清单.md） |
| AI 资讯源 | 官方发布渠道、行业媒体 |
| 平台热点 | 各平台热榜入口 |
| 选题池 | 读取已选题，避免重复 |

---

## 工作流程

```
【触发】每天 09:00 / 15:00 / 21:00
  ↓
① 抓取对标博主的近期内容（标题 + 摘要）
  ↓
② 抓取 AI 资讯源新增内容
  ↓
③ 抓取各平台热榜
  ↓
④ 三类内容合并去重
  ↓
⑤ 过滤：与你的定位无关的直接丢弃
  ↓
⑥ 有价值的 → 生成情报卡（来源 / 日期 / 核心事实 / 对我的影响 / 可用性评分）
  ↓
⑦ 高价值（评分≥4）的额外推一条到选题池
```

---

## 提示词要点

```
你是情报分析员。我给你一批抓取到的内容，你筛选并提炼。

输出（每条一张卡）：
# 情报：[一句话标题]
- 类型：平台热点 / 行业动态 / 工具更新 / 对标内容
- 来源：[名称 + 链接]
- 日期：[发布日期]
- 核心事实（3条内）：
- 对我的影响/可做的动作：
- 与我定位的相关性：1-5 分
- 有效期：长期 / 短期

规则：
1. **与我的定位无关的直接丢弃，不要勉强生成卡片**
2. 相关性低于 3 分的不生成
3. 只提炼事实，不要添加你自己的判断
4. 日期必须从原文提取，提取不到写"待补"
```

---

## 失败处理

| 情况 | 处理 |
|------|------|
 抓取失败 | 记录哪几个源失败，不影响其他源。连续 3 天失败 → 告警 |
| 抓到重复内容 | 用 URL + 标题指纹去重 |
| 抓到营销号软文 | 相关性打分时降权，标注"营销味重" |
| 内容过多 | 按相关性排序，只保留 Top 20 |

---

## 关键约束

1. **抓取范围必须是你指定的账号白名单**，不扩散。
2. **不抓取平台规则页面**——那是安全官的事，且抓取本身有风险。
3. **相关性 < 3 分不生成卡片。** 情报库塞满垃圾等于没有情报。
4. **它不做判断，只做提炼和过滤。**
