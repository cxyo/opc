> **这份文件是整个系统的最高约束。** 所有内容生产前必须过一遍，任何岗位发现与本清单冲突的内容，一律不产出、不发布。
> 版本：v1.1 · 2026-10-27 建档 · 最后更新 2026-10-27（v1.1 新增获客类红线：电话营销、短信营销、矩阵养号、导流交易）
> 维护：安全官（差异比对）+ 人（确认勾选）

## 使用说明

### 格式说明

每条红线包含 6 个字段，**结构化的目的是让质检官能逐条比对，而不是"参考着写"**：

```
平台 | 生效日期 | 禁止行为 | 处罚后果 | 来源 | 判定关键词
```

### 三级标记

| 标记 | 含义 | 处理方式 |
|------|------|---------|
| 🔴 **红线** | 明确禁止，触碰即封号/下架 | **绝对不生成、不发布**，命中即中止 |
| 🟡 **灰区** | 视情况判定，可能限流 | 生成前必须人工确认 |
| 🟢 **注意** | 有要求不满足会降权 | 自动加标记，发布前检查 |

### 本清单与国家政策的关系

平台红线是"平台层面"的禁止，国家政策清单（`禁区清单_国家政策.md`）是"法律层面"的禁止。**两者重叠时，取更严的。**

### 📌 判定要点（给质检官）

**"不诈骗"不等于"合法"。** 这是最常见的误判。

法律判断的关键前提是**是否取得用户同意**，不是"是否骗钱"：

```
✅ 合法：客户主动留资 + 明确同意接收营销 + 合理时段 + 拒绝即停
❌ 违法：买号码库 + 批量外呼 + 改号重拨 + 拒绝后换号再打
```

**"有退订"不等于"合法"。** 退订是事后补救，不能替代**事前明示同意**。

**营销话术不得出现导流暗示**，包括但不限于：加V、微芯、v.x、绿色软件、丝（私信）、私、扣1、看图、主页有惊喜。平台已上线 OCR 文字识别、方言谐音检测、人声分离技术。

## 七、质检官使用说明

### 比对流程

```
1. 读取禁区清单中"目标平台"相关的全部条目
2. 逐条检查待检内容：

3. 输出三段式结果：
   - 【命中】列出：平台 / 条款 / 原文位置 / 建议改法
   - 【疑似】列出：疑似触发的条款 + 需要人工确认的点
   - 【通过】说明已检查的条款数量
4. 命中 🔴 → 中止流程，不进入下游
5. 命中 🟡 → 转人工确认

```

### 特别注意

**判定关键词命中 ≠ 一定违规。** 关键词只是触发比对，AI 必须再判断语义。例如"绝对"一词，出现在"这绝对是我见过最好的"和"绝对不要这样操作"里，性质完全不同。

**反向检查同样重要**：如果内容里有某个关键词但上下文是**引用、批评、科普反面案例**，不算违规。
