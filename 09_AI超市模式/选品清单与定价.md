# 选品清单 · 摆什么货 / 不摆什么货

> 用途：决定 AI 超市货架上放哪些商品、什么价、什么顺序。
> 原则：宁可少摆，不可杂货铺。每层货架都要能摆满。

---

## 一、先定细分方向（只选 1-2 个）

基于账号定位卡「AI 提效 / 内容生产」，两个可选方向：

| 方向 | 优势 | 劣势 | 建议 |
|---|---|---|---|
| **A. AI 提效工作流** | 需求面宽，好找素材 | 竞争最激烈，同质化严重 | ✅ **主货架** |
| **B. 工业/制造业场景 AI 落地** | 几乎无人竞争，是护城河 | 受众窄，成交周期长 | ✅ **差异点**，靠内容层渗透 |

**结论：A 做规模，B 做壁垒。**
具体做法：A 负责拉人和收单，B 负责证明"我是真干过的人"。

> ⚠️ 不要开第三个方向。你只有一个人，摊薄必死。

## 二、四层货架 · 商品清单

### 引流层（免费·拉人）

| 商品 | 形式 | 成本 | 作用 |
|---|---|---|---|
| 21 个 AI 员工岗位说明书 | 文件 | 0 | 建立"这人懂行"的印象 |
| 8 步流水线工作流表 | 文件 | 0 | 让对方看懂全貌 |
| 8 步避坑清单 | 文章/图文 | 0 | 实用、易转发 |
| 每周免费额度盘点 | 系列内容 | 0（人工搜集） | **唯一引流品必须持续更新** |

**注意**：引流品不能只给一次。要做成**连载**（每周一期），
让老读者养成"每周来看一眼"的习惯。

---

### 内容层（教程·留人）

| 内容 | 频率 | 差异化要求 |
|---|---|---|
| 实战实测（跑通一个流程，贴真实数据） | 每周 1-2 篇 | 必须贴 token 消耗、耗时、返工次数 |
| 翻车复盘（哪里失败了，为什么） | 每月 1 篇 | **最容易被忽略但最能建立信任** |
| 行业场景深挖（产线/制造业里的 AI 落地） | 每周 1 篇 | 你的护城河，别人抄不走 |
| 对标拆解（拆别人的 AI 账号/课程） | 每两周 1 篇 | 帮读者省时间 = 导购价值 |

**差异化铁律**：
> 别人能给你的，Google 也能给。
> 别人给不了的，是**你跑过、翻过、修正过**。
> 每篇至少有一段是"我实测的结果"，不是"资料显示"。

## 三、不摆什么货（明确排除）

| 不做 | 原因 |
|---|---|
| ❌ 全品类 AI 工具清单 | 拼多多式价格战，且 Google 搜索即可 |
| ❌ 卖大模型 API 额度 | 微利、且你在跟巨头用钱硬拼 |
| ❌ 卖课（大课/训练营） | 交付成本极高，你现在没时间；先用资料包测需求 |
| ❌ 矩阵号/批量起号服务 | 违反平台规则，项目禁区库已列为红线 |
| ❌ 无人实体超市 | 已验证是泡沫 |
| ❌ 加盟/招代理 | 你一个人做不出交付，等有 10 个真实案例再考虑 |
| ❌ 短视频代运营 | 占用你大量时间，且效果不可控，稀释主线 |

## 四、上架顺序（重要）

不要一次全摆。**按这个顺序上，每上一层是下一层的前提**：

```
第 1 层：引流品（免费三件套）    ← 让对方进得来
   ↓
第 2 层：¥49 资料包              ← 第一次收费，验证有人愿意付钱
   ↓
第 3 层：¥99-299 代做服务        ← 稳定现金流 + 积累真实案例
   ↓
第 4 层：¥2000+ 企业咨询         ← 高价、限流、口碑放大器
   ↓
第 5 层：¥99 会员                ← 前四层都跑顺了再说
```

> **在第 2 层跑通之前，不要做第 4、5 层。**
> 一个月只上一个新商品，这是铁律。

## 五、定价测试清单

上线前逐条确认：

- [ ] 资料包 ¥49 是否偏低？→ 低于 50 元会被当成"垃圾货"，且拉低你后续所有产品的价格锚点
- [ ] 代做服务是否需要三档？→ 建议先只做一档，跑顺再加
- [ ] 是否提供"不满意不收尾款"？→ 是。这是转化率最高的一句承诺
- [ ] 企业咨询是否限流？→ 必须限。限流本身就是定价策略
- [ ] 是否有"不适合谁"？→ 必须有。写清楚反而提升信任
- [ ] 所有价格是否与货架页一致？→ 不一致会直接损失信任

| 指标 | 怎么算 | 本月 | 上月 | 变化 |
|---|---|---|---|---|
| 货架页访问量 | 后台/链接统计 | | | |
| 引流品领取数 | 私域新增好友 | | | |
| 资料包订单数 | 店铺后台 | | | |
| 代做订单数 | 手动记录 | | | |
| 企业咨询线索数 | 私信统计 | | | |
| 客单价 | 总收入 / 订单数 | | | |
| **复购率** | 老客订单 / 总订单 | | | |
| 内容产出数 | 实际发布篇数 | | | |
| 每篇带来的私域新增 | 新增/篇数 | | | |

**关键判断**：
- 货架页有访问但没人买 → 信任不够，检查有没有真实案例
- 有成交但没人进货架页 → 引流品太弱或入口太隐蔽
- 老客不复购 → 商品没有持续更新价值
