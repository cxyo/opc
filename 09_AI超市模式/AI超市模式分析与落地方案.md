## 0. 一句话结论

**这个模式你该做，但不是"开一家新超市"，而是把你已有的东西"摆上货架"。**

你的一人AI公司已经建好了内容层和资产层（85%、90% 完成度），  
缺的是**收银台**——把"别人问你怎么做"变成"你按一下就能下单"的入口。

**最小动作：把已有的 4 个赚钱入口（资料包 / 代做 / 私域促单 / 复盘）汇成一张  
"货架页"，挂在公众号菜单 + 小红书简介 + 闲鱼店铺，三处各放一个二维码。**  
这一步不花一分钱，两小时内能做完。

## 1. 先破题：视频讲的"AI超市"是哪种？

"AI超市"现在是个**被三个完全不同的东西共用的词**。看错了方向，投入的时间和钱会全部打水漂。

| 形态                                 | 是谁在做         | 卖什么              | 个人能做吗         |
| ---------------------------------- | ------------ | ---------------- | ------------- |
| **A. 政府主导型**<br />四川AI超市、陕西Token超市 | 省科技厅 + 中国电信等 | 算力、Token、数据、终端   | ❌ 只能当供应商或买家   |
| **B. 创业货架型**（本视频讲的）                | 个人 / 小团队     | AI 工具清单、教程、服务、接单 | ✅ **你能做**     |
| **C. 无人实体超市**                      | 缤果盒子、便利蜂等    | 真店面 + AI收银       | ❌ **已被验证是泡沫** |

### A. 政府主导型（最容易混淆，必须先排除）

四川AI超市 2026-10-22 正式上线，省科技厅主办、中国电信四川公司协办：

- 五大货架：算力、Token、数据、智能体、终端
- 170余种主流大模型 + 40余种行业垂类模型 + 60余款行业智能体 + 200余项行业服务
- 接入算力 118.8 EFLOPS，支持 16 种调度策略，宣称综合成本降低 40%
- 线上智能导购 3 秒匹配方案，线下 500 余名工程师交付
- 第一批入驻 200 余家供应商

**跟你没关系**：这是省级政府公共基础设施，准入门槛是硬性的——  
上架产品须提供**至少 10 万元业绩证明**。而且是"卖算力"，不是"卖内容认知"。

### B. 创业货架型（视频讲的就是这个）

多个独立来源交叉印证的核心定义：

> **AI 超市 = 货架 + 导购 + 交易**
>
> - **货架**：分类好的 AI 工具清单、教程文章、赚钱方法库
> - **导购**：告诉你"这个工具怎么用、这笔钱怎么赚"的攻略
> - **交易**：悬赏、接单、资料兑换等真实的价值交换动作
>
> **三个环节缺一个，都只是普通博客；凑齐了才是超市。**

商业逻辑不是"做模型"也不是"做应用"，而是：

> AI 行业进入"**工具过剩、认知稀缺**"阶段。模型越来越多、插件越来越多，  
> 但普通人不知道用什么、怎么用、怎么靠它赚钱。  
> **谁把"选择"这件事做明白了，谁就掌握了流量入口。**  
> 赚的是"信息差 + 操作差"的钱——用户为省时间付费、为确定性付费、为"有人趟过路"付费。

### C. 无人实体超市（血泪教训，必须知道）

2016-2019 年国内烧掉几十亿的死局，教训值得抄：

- **成本没省下来**：传感器、摄像头、RFID 标签（单个约 0.5 元）、后台系统，  
  硬件投入可达数千万
- **管理跟不上**：第一批进场的大多是互联网/投资人/传媒背景，不懂供应链和品控
- **人性之困**：2019 年某无人便利店 4 天内被同一人偷走近 800 件商品
- **亚马逊自己都撤了大部分门店**；缤果盒子 10-20 万/店的加盟费，  
  宣称"日销 300 元保本"，实际算不过来

> **一句话**：无人实体超市是"资本热捧型泡沫"，谁抄谁死。  
> 视频里的"AI超市"跟它**只是名字撞车**，内核无关。

## 2. 适不适合你做？

### 判断结论：适合，但要做"窄版"，不做"全家桶"

| 维度     | 判断     | 理由                            |
| ------ | ------ | ----------------------------- |
| 模式本身   | ✅ 成立   | 有真实需求：AI 工具过剩、认知确实稀缺          |
| 你的资源匹配 | ✅ 高度匹配 | 你已有内容层（85%）+ 资产层（90%）+ 21 个员工 |
| 你的定位优势 | ✅ 强    | "产线工程师 + AI 实践者"，别人没有的差异点     |
| 技术门槛   | ✅ 低    | 本地 Python + 扣子 Bot，已跑通        |
| 资金门槛   | ✅ 极低   | 20 元 API 就能跑一年                |
| 竞争强度   | ⚠️ 高   | 大量同类 AI 公众号已在做，必须靠"窄"取胜       |
| 政策合规   | ⚠️ 需注意 | 不能碰灰产（群控/养号/导流），你的禁区库已覆盖      |

### 三个必须知道的坑

**坑一：把超市开成杂货铺**  
什么方向都做，结果每层货架都摆不满。  
→ **你的对策**：只做 **1-2 个细分方向**。基于你的定位卡，  
建议锁定「**AI 提效工作流**」+「**工业/制造业场景 AI 落地**」——  
后者是你的护城河，没人会跟你抢。

**坑二：只摆货架不开收银台**  
文章写了无数篇，却没有任何一个"下单"入口。  
→ **你的对策**：每一篇文章、每一条私信，末尾必须有一个明确的下一步。  
你项目里已经有「私域促单四式」，但**还没接成"按下单"**。

**坑三：忽略会员，流量留不住**  
每天都要重新拉新。  
→ **你的对策**：先不急着做会员。先用"资料包"做客户过滤器  
（你自己在《资料包价值设计卡》里写了：**资料包是过滤器，不是利润主体**）。

### 关于"是风口还是泡沫"的诚实判断

搜索到的批评文章主要针对**无人实体超市**（C 类），不是这个内容货架模式（B 类）。  
但对 B 类，我看到三个真实风险：

1. **同质化极严重**——大量 AI 公众号、知识星球、社群都在做同样的事。  
   你的护城河只能来自"**真实案例 + 行业深度**"，不能来自"整理得更全"。
2. **信息差会失效**——今天你整理的工具清单，明天别人也能整理。  
   真正能长期变现的是**服务层**（代做、企业改造），不是内容层。
3. **免费额度红利会退潮**——现在各家大模型疯狂送额度，这是引流品；  
   等补贴退了，引流层就要换成真本事。

> **所以我的建议是：把"AI超市"当成你现有业务的"包装形态 + 收银台"，  
> 而不是当成一门新生意。** 内容是手段，收银才是生意。

## 3. 具体怎么做（分层货架 + 落地动作）

### 3.1 货架四层怎么摆

| 层       | 内容              | 作用     | 你的现有资产             | 要补什么               |
| ------- | --------------- | ------ | ------------------ | ------------------ |
| **引流层** | 免费额度、羊毛、签到、工具清单 | 拉人     | 账号定位卡、选题池 30 条     | 做成一个固定栏目《每周免费额度盘点》 |
| **内容层** | 教程、实测、避坑        | 留人     | 8 步流水线、21 个岗位、三篇案例 | 让内容有"实测数据"标签       |
| **服务层** | 接单、代做、企业改造      | **赚钱** | 商品官 A13、转化官 A18    | **⚠️ 缺收银台，最大短板**   |
| **资产层** | 资料库、SOP、人脉      | 复购     | 资料包 28 个文件、FAQ 库   | 打包成可售商品            |

### 3.2 三步落地（按优先级，别跳步）

#### 第一步：先做"货架页"（今天就能做，2 小时，0 成本）

**这一页就是你的收银台。** 不需要开发网站，一个 PDF 或一篇公众号文章就够。

结构建议：

```
【我的 AI 超市 · 货架总览】

━━━ 引流区（免费拿走）━━━
① 每周免费额度盘点（AI 工具白嫖清单）
② 21 个 AI 员工岗位说明书（可复制）
③ AI 内容流水线避坑清单

━━━ 商品区（付费）━━━
④ 【爆款】AI 内容流水线实战包 ¥49
   └ 一句话价值：别人 3 个月踩坑，我 6 天跑通
⑤ 代做服务：公众号文章 / 小红书图文 / 详情页
   └ ¥199/篇起，AI 内容流水线交付
⑥ 企业 AI 改造咨询（把你的产线方法论搬过去）
   └ 按项目收费

━━━ 会员区（¥99/年）━━━
⑦ 每周实测内容 + 提示词库更新 + 优先答疑

👉 点这里下单 / 加微信：XXXXXXXX
```

**三个入口都要放**：

- 公众号 → 自定义菜单「AI超市」
- 小红书 → 简介里挂链接
- 闲鱼/面包多 → 店铺简介

> **关键**：这一页做完，你的"内容"才有了变现出口。  
> 现在你的内容是"发出去就没了"，货架页是"发出去能收钱"。

#### 第二步：把服务层的三个产品定义清楚（本周）

| 产品          | 定价       | 交付物           | 交付用哪个员工             |
| ----------- | -------- | ------------- | ------------------- |
| AI 内容流水线实战包 | ¥49      | 28 个文件 + 使用说明 | 已完成 ✅               |
| 代做服务（单篇）    | ¥199 起   | 公众号/小红书/详情页   | A07→A10→A09→A11 全链路 |
| 企业 AI 改造咨询  | ¥2000+ 起 | 诊断报告 + 落地工作流  | A03→A05→A07 + 人工    |

**代做服务的成本你算过吗？**  
跑一篇完整链路约 ¥0.12（DeepSeek），**几乎零边际成本**。  
¥199 的服务，成本 0.12，毛利率 99.9%。  
这是你最该主推的产品——但前提是能稳定交付出客户满意的质量。

#### 第三步：内容层补"实测感"（持续做）

现在你的文章是"方法论"，需要往"**我实测过**"靠：

- 贴出真实的 token 消耗、耗时、返工次数（**你已经有真实数据了**）
- 贴出真实的失败案例（去AI味失败了几次、质检官拦下了什么）
- 贴出产线现场的反例（AI 建议在产线为什么行不通）——**这是你独有的，别人抄不走**

> **你的定位卡里写了"他们给工具清单，我给跑通的参数和踩过的坑"。  
> AI 超市模式让这句话的价值翻倍——因为货架上的货，本来就该是实测过的。**

## 4. 怎么放进一人AI公司？

### 4.1 结构映射

```
现有一人AI公司                  加一层"超市"
─────────────────────────────────────────────────
08_可运行系统/                →  09_AI超市模式/
  21 个 AI 员工（内容生产）       ├── 货架页.md          ← 新增，收银台
  8 步流水线（出稿）              ├── 选品清单.md        ← 新增，摆什么货
  8 步商品链（出详情页）           ├── 定价与话术.md      ← 新增，怎么卖
  禁区库（合规兜底）              └── 会员权益设计.md    ← 新增，复购
                                  ↓
05_产品交付/（商品）           →  货架区的货
02_知识库种子/（内容源）        →  内容层的库存
01_Agent提示词/（能力）        →  导购的底气
```

### 4.2 需要的岗位补充

现有 21 个岗位覆盖了"生产内容"，但超市模式还需要 2 个新角色：

| 编号      | 岗位  | 层级 | 干什么                    | 为什么现有岗位不够                   |
| ------- | --- | -- | ---------------------- | --------------------------- |
| **A22** | 选品官 | L1 | 判断什么值得上架、什么该下架、定价、算毛利率 | A13 商品官管"怎么写详情页"，不管"该不该卖这个" |
| **A23** | 货架官 | L4 | 维护货架页、菜单、入口一致性、上下架     | A11 发布官管"发到哪"，不管"货架摆什么"     |

> 这两个岗位**不用从零写**——照着现有 21 份岗位说明书的格式做就行，  
> 我可以直接生成。

## 7. 我的最终建议

**做。但把它当成"给你的内容装一个收银台"，而不是"开一家新公司"。**

理由有三：

1. **你已经建好了 80%**——内容层、资产层都接近完成，AI 员工系统已跑通，  
   资料包已成型。这不是从零开始，是"最后一段路"。
2. **成本极低**——20 元 API 费 + 两小时做货架页。这是你做过的  
   投入产出比最高的一件事。
3. **这是内容变现的最短路径**——内容→信任→私域→成交，  
   你项目里**唯一断的就是最后一环**。货架页就是把它接上。

**但要清醒**：这个模式的天花板不在"货架做得多好看"，在  
**"服务层能不能稳定交付"**。资料包赚的是小钱，  
真正的钱在代做和企业改造——而那需要真实案例背书。  
所以 W1-W2 先跑通一个真实成交，比做十篇货架介绍都重要。
