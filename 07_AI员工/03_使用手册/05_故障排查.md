# 使用手册 · 故障排查

> 按**现象**查。每条给出最可能的原因和具体处理。

---

## 一、系统级故障（先查这里）

### 🔴 质检官放行了违规内容

**这是最严重的一类问题。** 按顺序查：

| 步骤 | 检查 | 处理 |
|------|------|------|
| 1 | 禁区库是否挂在质检官上 | 挂上 |
| 2 | 禁区分段是否被切碎 | 手动分段，一条禁区一段 |
| 3 | 段首是否有平台前缀 | 加前缀，让它能整段过滤 |
| 4 | 提示词里「禁区必须逐条比对」还在吗 | 补回 |
| 5 | 提示词里「关键词命中必须做语义判断」还在吗 | 补回（这条可能反向导致漏判） |

**如果以上都对还漏判**：升级到「代码节点预过滤」方案（见 `../02_扣子搭建手册/02_工作流编排.md` 第 2.4 节），把完整禁区文本直接塞进变量，不依赖检索。

**临时措施**：这一周手动复核每篇终稿。

### 🔴 质检官误报太多（天天挑刺）

| 原因 | 处理 |
|------|------|
| 禁区分段太碎，命中了半句话 | 合并成完整条款段 |
| 「关键词命中必须做语义判断」这条约束丢了 | 补回提示词 |
| 段首关键词太宽泛 | 改具体，比如把「虚假宣传」改成「月入XX万、保证有效、100%有效」 |

**判断标准**：如果它把干净的稿子也判不通过，就是误报。跑一次 `../02_扣子搭建手册/04_调试验收.md` 里的「干净稿要放行」测试。

### 🟡 Bot 输出的格式变了

```
① 提示词是不是被改了 → 对比 ../01_Bot提示词/Axx_xxx.md
② 「风格要求」段还在吗 → 少了会加寒暄
③ 「你的输出规范与判断规则」段还在吗 → 少了会自由发挥
```

### 🟡 Bot 完全不引用知识库

```
① 知识库挂上了吗
② 文件解析完成了吗（状态是"可用"？）
③ 问法里有文档里的关键词吗
   → 扣子做语义匹配，用户说"能不能吹牛"、库里写"禁止虚假宣传"，命中会弱
   → 测试时把关键词带上："抖音关于虚假宣传的禁令是什么"
④ 段首补关键词，让检索更容易命中
```

### 🟡 Bot 每次输出都不一样

```
温度太高 → 调到 0.2-0.3（扫描类）或 0.7-0.8（创作类）
上下文里没有变量 → 引入变量，增加确定性
```

## 二、内容质量问题

### 写出来像 AI 写的

**先分清是哪种「像 AI」：**

| 表现 | 根因 | 处理 |
|------|------|------|
| 句式太整齐、四段一样长 | 去AI味官没跑够 / 温度不够 | 温度调到 0.9，跑第二遍 |
| 空洞的形容词太多（赋能、闭环、颗粒度） | 风格指纹卡是空的 | **补语料**，这是根本解法 |
| 逻辑太完美、没有情绪 | 没有真实素材 | 补真实经历 |
| 开头总是"随着……的发展" | 风格指纹没粘进去 | 检查风格指纹卡是否分段切碎 |

**根本解法只有一个：补真实素材。** 去AI味是补救，素材才是源头。

### 内容太空、没说服力

```
选题有问题 → 选题官的「素材准备度」评分虚高了
素材有问题 → 素材官收了没用的东西
或者  → 你在选题时挑了「素材准备度 < 3 分」的题
```

**检查选题时的四维评分是不是认真打的。** 素材准备度低于 3 分的题不该做。

### 文章有事实错误

```
□ 质检官的「事实与错误检查」段跑了吗
□ 撰稿官输出里的【待补】都处理了吗（质检官应该判不通过）
□ 数字有来源吗
```

**核心问题**：撰稿官编造了数据。检查提示词里「素材库里没有的事实和数据不要编，需要具体数字的地方标注【待补】」这条在不在。

### 文章有重复感（多篇像一篇）

```
□ 拆解官每次给的是同一类骨架吗 → 换参考文章
□ 选题角度真的不同吗 → 选题官去重逻辑
□ 开头三部曲用腻了 → 平台规则库里的「开头三部曲」需要变体
```

## 三、工作流故障

### 节点输出为空

```
① 单独跑上游节点 → 看它有没有输出
② 上游报错了吗 → 看运行日志
③ 变量名对吗 → 逐字比，注意大小写
④ 类型对吗 → 文本 vs 数组
```

### 分支总走错边

```
质检官输出的判定带书名号（【通过】），扣子条件节点匹配可能出问题
→ 在质检官提示词里加一行输出机器可读值：
   verdict_code: PASS | BLOCK_VIOLATION | BLOCK_AI | NEED_HUMAN
```

详见 `../02_扣子搭建手册/02_工作流编排.md` 第 2.3 和 2.4 节。

### 工作流跑到一半停

```
看运行日志 → 找第一个出错的节点 → 单独跑它
常见原因：
  节点超时 → 提示词太长 / 模型慢 → 拆分节点或换快模型
  变量缺失 → 上游没输出这个变量
  API 报错 → 公众号 IP 白名单 / token 过期
```

### 工作流跑一次要好几分钟

```
① 节点太多 → 主生产链 9 个节点，每个大模型调用都要时间
② 串行太多 → 能并行的并行（比如质检官和拆解官不冲突时可并行）
③ 模型太慢 → 扫描类节点换便宜模型
④ 先手动跑通 → 手动调用是 3 分钟，自动 9 分钟是正常的
```

## 四、发布故障

### 公众号发布失败，无报错

**90% 是 IP 白名单。** 后台 → 设置与开发 → 基本配置 → IP 白名单，把服务器 IP 加进去。

其他可能：
- access_token 过期（有效期 2 小时，需要缓存机制）
- 封面图 thumb_media_id 无效
- 正文 HTML 含被过滤标签

### 小红书/抖音发布失败

```
① 登录态还在吗 → 浏览器 cookie 失效，重新扫码
② 页面改版了 → 选择器失效，需要更新自动化脚本
③ 触发风控 → 频率太高，降频
```

### 发布成功了但没有阅读量

```
□ 内容被限流了吗 → 平台后台看违规记录
□ AI 内容声明勾了吗 → 没勾会被限流
□ 有站外导流暗示吗 → 谐音、拼音、符号变体都算
□ 是不是发完 2 小时内改过 → 判为异常运营
□ 是不是新号期发太快 → 单账号每天 1 篇，新号期 1 篇/2 天
```

**别急着改策略。** 先看后台有没有违规提示——很多「没量」其实是「被限流」。

### 被平台警告了

**立即降级到全手动，并按这个顺序处理：**

```
① 找到那篇内容（publish_log 里查）
② 逐条比对禁区清单（用 A10 质检官）
③ 找出触了哪条
④ 检查质检官为什么没拦住 → 补禁区、修分段
⑤ 手动改稿或删除
⑥ 一周内不自动发布
```

**不要申诉到封禁为止。** 一次警告是提醒，连续三次是定性。

## 五、效率问题

### 每天花的时间太长

```
□ 是不是每个 Bot 都在重跑？ → 通过的不重跑
□ 质检报告是不是逐条在读？ → 只看 P0 和判定
□ 素材是不是自己分类了？ → 直接丢 Inbox，让素材官做
□ 选题是不是纠结太久？ → 5 分钟内决定
```

### 产出速度跟不上

```
□ 是不是想做太多平台？ → 先只做公众号
□ 是不是每篇都追求完美？ → 前 10 篇允许不完美
□ 是不是选题太大？ → 选题要小到"一次能写完"
```

### 不知道该做什么

回到 `02_每日操作手册.md` 第一节。看三个数：
- 过去 7 天发了几篇
- 选题池里有几个可选
- Inbox 是不是空的

**如果选题池空的 → 去补素材；如果 Inbox 空的 → 去收集；如果都够但没发 → 是执行问题不是系统问题。**

## 六、状态判断：系统是否健康

每周问一次：

| 检查项 | 健康 | 有问题 |
|--------|------|--------|
| 禁区库有没有更新过 | 本月内更新过 | 超过 1 个月没动 |
| 质检官误报率 | < 20% | > 50% |
| publish_log 是否完整 | 连续无断档 | 断档多 |
| Inbox 是否清空 | 每周清空 | 积压 > 20 条 |
| 选题池是否有 5+ 个可选 | 是 | 少于 3 个 |
| 素材准备度高的选题占比 | > 50% | < 30% |

**任何一项亮红灯，先修那个。** 不要同时修多个。

## 七、快速判断表

| 现象 | 先查 | 再查 |
|------|------|------|
| Bot 不听话 | 提示词被改 | 知识库挂载 |
| 内容像 AI | 真实素材缺失 | 风格指纹卡 |
| 内容太空 | 选题素材准备度 | 素材质量 |
| 质检漏判 | 禁区分段 | 检索方案 |
| 质检误报 | 语义判断约束 | 关键词粒度 |
| 工作流中断 | 运行日志 | 变量映射 |
| 发布失败 | IP 白名单 | 登录态 |
| 没流量 | 后台违规记录 | 内容形态 |
| 效率低 | 每日手册自查表 | 砍掉的动作 |

## 八、还是搞不定

按这个顺序做**最小复现**：

```
① 复制一份 Bot
② 只留最简提示词（只保留输出规范 + 核心约束）
③ 手动喂一个最简单的输入
④ 逐步加回其他部分，每加一次测一次
```

**哪一步开始出问题，问题就在那。** 这比读十篇排查指南快。
