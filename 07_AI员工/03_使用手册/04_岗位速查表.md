## 二、按层级查（谁在什么时候跑）

### L0 约束层 · 横切全程

| 岗位 | 什么时候跑 | 自动化 | 产出到哪 |
|------|-----------|--------|---------|
| **A01 安全官** | 每周一 10:00 | L1 自动 | 差异表 → **你确认** → 禁区清单 |
| **A02 政策官** | 每月 1 号 07:00 | L1 自动 | 差异表 → 政策清单 + 候选选题 |

## 三、三个永久人工闸（不可下调）

| 岗位 | 闸点 | 为什么 |
|------|------|--------|
| **A18 转化官** | 所有对外消息 | 直接接触钱和客户承诺 |
| **A13 商品官** | 上架前 | 虚假宣传是法律风险 |
| **A10 质检官** | 判定「需人工确认」时 | 封号不可逆 |

**外加三个日常人工动作**：终稿确认（每篇 3 分钟）、AI 声明勾选（每篇 10 秒）、禁区审阅（每周 30 分钟）。

## 七、什么时候该找哪个岗位（反查）

| 情况 | 找谁 |
|------|------|
| 内容没人看 | A12 流量官（找规律）+ A14 复盘官（看历史） |
| 内容看了但不买 | A18 转化官（看异议）+ A13 商品官（看详情页） |
| 选题写不出好题 | A03 情报官（换输入）+ A05 选题官 |
| AI 检测过不了 | A09 去AI味官 + **补真实素材**（根本解法） |
| 一直违规 | A01 安全官（禁区更新）+ A10 质检官（漏判排查） |
| 内容太空 | A04 素材官（Inbox 攒料）+ 手工补经历 |
| 转化率低 | A19 品牌实体官（客户搜不到你）→ A16 GEO官 |
| 交付客户不满意 | A21 交付官（验收标准不清） |
| 不知道该做什么 | `02_每日操作手册.md` 第一节 |
