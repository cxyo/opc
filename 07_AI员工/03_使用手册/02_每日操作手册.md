# 使用手册 · 每日操作手册

> 每天两套动作：**早上一套 30 分钟，晚上一套 15 分钟**。
> 自动化程度再高，这两套动作也保留——它们是你的方向盘，不是负担。

---

## 一、早上一套（30 分钟）

### 1. 看选题池（3 分钟）

打开 `../04_人类工位/state/选题池.csv` 或扣子里的选题官 Bot。

```
□ 从 4-6 个候选选题里挑 1 个（最多 2 个）
□ 挑的标准：
   - 素材准备度 ≥ 3 分（没素材就别做）
   - 你有真实经历可以讲（这条最重要）
   - 不触禁区
□ 把选中的题记下来
```

**没选题可用？** 说明情报源或素材不够。去看 `03_知识库/00_Inbox/`，把这周看到的好东西丢进去，让素材官整理。

### 2. 补真实素材（10 分钟）

**这一步是整个系统里你不可替代的部分。**

打开笔记，写下：
- 这件事你实际遇到时是什么样（场景、时间、具体数字）
- 你当时怎么处理的
- 结果是什么

**不要写"很多人遇到""效果很好"这种没有具体细节的东西。** 去AI味官和 AI 检测都靠这些细节。

**素材不够时的处理**：在选题上打个标，写作时让撰稿官把需要具体数字的地方标【待补】，你后面补上。**不要让 AI 编。**

### 3. 跑生产链（12 分钟）

手动跑一遍，每个 Bot 依次喂：

```
□ 拆解官 ← 1-2 篇同赛道爆款（URL 或全文）+ 你的选题
□ 撰稿官 ← 骨架 + 你的真实素材 + 目标平台
□ 质检官 ← 初稿 + 目标平台
   → 如果【打回】→ 改稿官 → 去AI味官 → 质检官复检
□ 你确认终稿
```

### 4. 平台适配 + 发布（5 分钟）

```
□ 发布官 → 生成各平台版本
□ 人工读一遍每个平台的版本（这是必须的）
□ 手动发布 / 走发布工作流
□ **AI 内容声明勾上**（小红书/抖音）
□ publish_log 记录（30 秒）
```

## 二、晚上一套（15 分钟）

### 1. 收集（5 分钟）

```
□ 今天刷到的值得存的内容 → 丢进 ../../03_知识库/00_Inbox/
□ 客户消息 → 存到 客户与商机
□ 看到同行的好内容 → 记下链接和一句"好在哪"
```

**不要分类，不要写格式。** 素材官会整理。你只管丢。

### 2. 处理客户消息（5 分钟）

```
□ 打开闲鱼/面包多/小红书私信
□ 转化官 A18 → 出回复草稿
□ **你必须逐条看过再发**
□ 涉及金额、承诺、退款、纠纷 → 你自己回
```

### 3. 记一笔（5 分钟）

```
□ publish_log 补全（如果白天没记）
□ 今天的观察写 1-3 句进 ../../03_知识库/00_Inbox/复盘手记.md
   （哪篇数据好/哪个选题有意思/客户问了什么）
```

## 三、每周一套（90 分钟）

安排在固定时间（比如周日晚上）。五件事：

```
□ 30 分钟  禁区审阅
           → A01 安全官的差异表 → 你逐条勾 → 写入禁区清单
           → ../04_人类工位/人工确认清单.md

□ 15 分钟  选题池体检
           看完这周 4-6 个候选选题的表现分
           砍掉表现持续差的类型，加权表现好的

□ 20 分钟  复盘官跑一次（本周数据）
           把平台后台导出的数据丢进 Inbox
           看「本周结论」那 3 条

□ 15 分钟  FAQ 库更新
           把这周的高频问题沉淀进去

□ 10 分钟  素材官跑一次 + Inbox 清空
```

**第 10 分钟的「Inbox 清空」很重要。** 堆积的 Inbox 会让你逃避整个系统。

## 四、每月一套（2 小时）

```
□ 30 分钟  品牌实体检查
           → A19 品牌实体官
           重点看：这月有没有新的渠道用了不一致的名称/定位

□ 20 分钟  AI 提及实测
           → A16 GEO 官
           问 AI 10 个客户会问的问题，记录你的名字出现位置

□ 30 分钟  系统复盘
           → ../02_扣子搭建手册/04_调试验收.md 第六节
           哪些岗位在空转？哪些提示词该重写？

□ 20 分钟  政策检查
           → A02 政策官
           这个月有没有新的 AI 创作法规？

□ 20 分钟  手动补一批真实素材
           把这个月的经历整理进案例库
```

## 五、什么情况下该停掉自动化

**这三条任一出现，立刻降级到全手动：**

| 信号 | 原因 | 动作 |
|------|------|------|
| **收到平台警告或内容被限流** | 有内容触了规则 | 找出那篇，人工分析，必要时停掉整个工作流重查 |
| **质检官连续 3 次误报** | 它的判断不可信了 | 检查禁区分段，重写「语义判断」约束，暂缓自动放行 |
| **一周发出去的内容阅读量集体下滑** | 可能不是内容问题 | 先查违规历史、账号状态，再查内容 |

**降级不是失败，是系统在工作。** 它在告诉你规则变了。

## 七、最省时间的做法

**素材随手丢。** 看到好东西就丢进 Inbox，10 秒。不要分类、不要写笔记、不要起标题。素材官会做这些。

**选题不要挑太久。** 在 4-6 个里挑一个「素材够 + 我有经历」的，5 分钟内决定。纠结 20 分钟选一个题，不如用这 20 分钟写内容。

**质检报告不要逐条重读。** 只看「必须修改项 P0」和判定结果。P1/P2 建议跳过——那些往往是主观的。

**发布后 2 小时内什么都别做。** 改稿、删除、重发都算异常运营。想改就发下一篇。
