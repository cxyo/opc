# 使用手册 · 每周维护清单

> 每周一次，90 分钟。**这一小时决定下周所有工作的质量。**
> 建议固定时间（比如周日晚上 20:00），别拖到"有空的时候"。

---

## 一、为什么周维护不可省

系统的产出质量不取决于 AI 多聪明，取决于**输入有多干净**。

| 不维护的后果 | 表现 | 多久后显现 |
|-------------|------|-----------|
| 禁区不更新 | 违规内容发出去 | 规则更新后 1-2 周 |
| Inbox 积压 | 素材库是空的，选题官出不了好题 | 2-3 周 |
| FAQ 不更新 | 售后官每次都要人工 | 1 个月 |
| 表现分不回填 | 选题官一直出你早就写过的题 | 1 个月 |
| 品牌口径不统一 | 客户搜不到你，或搜到的是别人 | 2 个月 |

**这五件事都不难，但都不做，系统会在一个月内退化成"一个会写稿的聊天机器人"。**

## 二、90 分钟分配

```
□ 30 分钟  禁区审阅（A01 安全官）      ← 最重要

□ 20 分钟  复盘（A14 复盘官）
□ 15 分钟  FAQ 更新
□ 10 分钟  Inbox 清空（A04 素材官）
```

## 三、第 1 项 · 禁区审阅（30 分钟）

### 操作

```
1. 打开扣子的 A01 安全官 Bot
2. 把这周看到的平台公告丢进去
   （格式：平台 / 标题 / 链接 / 原文摘录）
   没有公告 → 正常，输出「本期无更新」，跳到第 2 项
3. 安全官输出差异表
4. 打开 state/待确认清单.json
5. 逐条填「我的判断」
6. 同意的 → 手动写入禁区清单 → 「已写入禁区」改"是"
7. 更新 ../../03_知识库/wiki/10_禁区/ 下的对应文件
8. 重新上传到 KB_禁区 知识库
```

### 判断原则

| 差异类型 | 动作 | 注意 |
|---------|------|------|
| **新增收紧** | ✅ 全部同意，标 🔴 | 这类必须全部进禁区，没有例外 |
| **新增注意** | ✅ 同意，标 🟡 | 影响写法，不是禁发 |
| **表述变化** | ✅ 同意，只更新判定关键词 | 实质没变，别大动 |
| **口径放宽** | ⚠️ 逐条看 | 放宽可能是"换个说法禁" |
| **无法判定** | 🔍 你去查 | AI 判不了，不要猜 |

### 判定关键词要具体

```
❌ 「虚假宣传」
✅ 「保证有效」「100%」「包教包会」「月入XX万」「稳赚」
```

**判定关键词是质检官检索的抓手。** 太宽泛 → 误报；太窄 → 漏报。

### 平台公告去哪找

| 平台 | 去哪看 |
|------|--------|
| 抖音 | 抖音黑板报（公众号）、创作者中心公告 |
| 小红书 | 薯管家（公众号）、社区公约页 |
| 闲鱼 | 闲鱼黑板报（公众号）、社区规则页 |
| 公众号 | 微信公众平台运营规范页 |

**把这些链接存成书签。** 每周花 5 分钟扫一遍标题，有变化就丢给安全官。

## 四、第 2 项 · 选题池体检（15 分钟）

### 操作

```
1. 打开 state/选题池.csv
2. 看 status = 候选 的选题
3. 砍掉这周没被选中的（连续 2 周没人选 = 不吸引人）
4. 看 published 的选题的 performance_score
5. 找出高分类型 → 记下来
6. 找出低分类型 → 记下来
7. 找出「素材准备度 < 3 分」但被你选了的选题 → 反思是不是太将就
```

### 判断标准

| 观察 | 结论 | 动作 |
|------|------|------|
| 某类型连续 3 篇高分 | 这个方向是你的 | 加权：选题官多出这类 |
| 某类型连续 3 篇低分 | 这个方向不行 | 砍掉：减少这类 |
| 候选池 < 3 个 | 素材/情报不足 | 去补 Inbox |
| 候选池 > 10 个 | 供给过剩 | 提高入选门槛 |

### 关键动作

**把结论写回 `选题池.csv` 的 `notes` 列**，比如「痛点型表现好，2026-10 那 3 篇都是 2 倍均值」。

**下一周选选题时会用得上。** 光记在脑子里，等选题官重写提示词时就丢了。

---

## 五、第 3 项 · 复盘（20 分钟）

### 操作

```
1. 从各平台后台导出上周数据
   公众号：数据统计 → 导出
   小红书：创作中心 → 数据中心 → 导出
   抖音：创作者中心 → 数据 → 导出
2. 把导出的文件丢进 ../../03_知识库/00_Inbox/
3. 跑 A14 复盘官
4. 看「三、本周结论」那 3 条
5. 把 publish_log 的 views/likes/comments/follows 回填
6. 看有没有流量骤降 → 有的话查违规历史
```

### 重点看三件事

```
□ 本周结论 3 条 —— 有数据支撑吗？还是感觉？
□ 选题池表现分更新 —— 跟你的判断一致吗？
□ 异常预警 —— 有没有平台流量异常？
```

### 如果数据没回填

**复盘官会输出"数据未更新完"或只出统计不出结论。** 这时候：

- 样本 < 10 篇 → 正常，别下结论
- 平台导出失败 → 用手工记的数，标注"数据来源受限"
- **不要让 AI 猜数字** —— 猜出来的表现分会污染选题官

## 六、第 4 项 · FAQ 更新（15 分钟）

### 操作

```
1. 看这周的客户消息（闲鱼/面包多/私信）
2. 找出被问了 2 次以上的问题
3. 检查 FAQ 库里有没有
4. 没有 → 写进去
5. 有但答得不好 → 改
6. 顺便检查商品详情页：这些问题在详情页里有没有提前回答？
```

### FAQ 库位置

`../../03_知识库/wiki/05_客户与商机/FAQ库.md`

### FAQ 写法

```
问题：客户原话（不要改写成书面语）

回答：
- 先给直接答案（1-2 句）
- 再给理由/依据
- 最后给下一步（如果有）

标签：#产品使用 #价格 #交付
```

**用客户原话当问题。** 你改成书面语之后，就搜不到客户真正会打的那句话了。

### 顺带做一件事

**高频问题 → 商品详情页。** 如果 5 个人问同一个问题，说明详情页没写清楚。改详情页比在客服环节反复回答更省力。

## 七、第 5 项 · Inbox 清空（10 分钟）

### 操作

```
1. 扫一眼 ../../03_知识库/00_Inbox/ 有什么
2. 跑 A04 素材官
3. 素材官整理完会清空 Inbox
4. 检查有没有"待人工处理"的条目 → 处理掉
```

### 为什么必须清空

**堆积的 Inbox 会让你逃避整个系统。** 每次看到 30 条未处理的东西，你会下意识先做别的。

Inbox 里通常有三类：

| 类型 | 去向 |
|------|------|
| 有用的资料 | 素材卡 → wiki |
| 重复的 | 合并进已有卡 |
| 没用的 | 归档 |

**如果这周 Inbox 又是空的** → 说明你收集不够。情报官没东西可筛。

## 十、周维护的判断标准

**做完了的标志**：

```
□ 禁区清单本周更新过（或确认无更新）
□ publish_log 连续一周无断档
□ 选题池里没有"连续 2 周没人选"的僵尸选题
□ FAQ 库至少新增 1 条（或确认这周没有高频问题）
□ Inbox 是空的
```

**做不到的就只做一项：禁区审阅。** 这一项的投入产出比最高——30 分钟换掉封号风险。
