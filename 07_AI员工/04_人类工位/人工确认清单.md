# 人类工位 · 人工确认清单

> **这个系统里 AI 替代不了的部分。**
> 不是"待完善"，是**故意保留**的。

---

## 一、为什么保留人工闸

三句话讲清楚：

1. **封号不可逆。** 内容发出去删不回来，账号封了积累全没。所有 AI 辅助的行为，出错成本都由你承担。
2. **判断题不是计算题。** "这个选题值不值得做""这条规则重不重要""这个客户是真买还是问着玩"——这些需要立场和经验，不是概率。
3. **AI 越权一次，你就再也不信它了。** 一个偷偷放行违规稿的质检官，比没有质检官更危险。

所以这里的每一道闸，**都不建议省**。

---

## 二、永久人工闸（三道，不可下调）

### 闸门 1 · 终稿确认（每篇 3 分钟）

**位置**：A10 质检官 →【通过】之后 → A11 发布官之前

**看什么：**

```
□ 标题像你会说的话吗（不是 AI 味标题）
□ 开头三行能不能抓住人
□ 有没有你自己经历过的部分（≥20%）
□ 结论/方法你自己信吗
□ 没有你不敢对读者说的话
□ 【待补】占位符都处理了
```

**怎么判定**：**读一遍，用你自己的话说一句"这篇在讲什么"。** 说不出来 = 稿子有问题。

**常见翻车**：AI 写的稿子逻辑通顺、读着顺，但**没有一句是你会说的**。这说明真实素材没进去，回炉补素材，不要靠改措辞硬救。

---

### 闸门 2 · AI 内容声明勾选（每篇 10 秒）

**位置**：发布到小红书/抖音时

**看什么**：这篇内容用了 AI 辅助吗？

```
□ 用了 AI 生成/改写文字 → 勾选 AI 生成声明
□ 用了 AI 生成图片/配音/画面 → 勾选对应项
□ 全 AI 生成 → 不勾"原创"（平台规则：全 AI 生成内容不可申请原创）
```

**为什么重要**：

- 《AI生成合成内容标识办法》2025-09-01 已施行，**发布者有主动声明义务**
- 小红书《社区公约2.0》（2026-01）明确要求 AI 辅助创作必须主动标识
- 抖音已部署方言谐音检测 + 人声分离技术，漏标是可直接判定的事实

**漏标的后果**：限流 → 多次违规 → 封号。这条几乎没有侥幸空间。

---

### 闸门 3 · 对外消息确认（A18 转化官 / A15 售后官）

**位置**：AI 给出回复草稿之后

**看什么：**

```
□ 语气像你吗（不是客服腔）
□ 承诺的东西你敢兑现吗
□ 有没有引导站外交易（微信/支付宝/私下转账）
□ 价格、交付、退款政策准确吗
□ 对方情绪激烈 → 你自己回，别让 AI 处理
```

**三类必须你自己回**：

| 类型 | 原因 |
|------|------|
| 涉及金额、承诺、退款 | 法律关系 |
| 客户情绪激动/投诉 | 冲突需要人 |
| 合作咨询、批量采购 | 商务判断 |

## 三、定期人工动作（三个）

### 动作 1 · 禁区审阅（每周 30 分钟）

**位置**：A01 安全官的差异表 → 写入 `禁区清单_平台红线.md`

**看什么：**

```
□ 差异表里「新增收紧」的条目 —— 这类必须全部同意
□ 「口径放宽」的条目 —— 放宽了是不是可以做更多事了
□ 「表述变化」的条目 —— 判定关键词要不要跟着改
□ 「无法判定」的条目 —— 需要你补链接或截图才能判
```

**判定原则**：

| 情况 | 动作 |
|------|------|
| 新增禁止行为 | ✅ 同意，标 🔴 |
| 新增注意事项 | ✅ 同意，标 🟡 |
| 表述变化但实质没变 | ✅ 同意，只更新判定关键词 |
| 口径放宽 | ⚠️ 谨慎，放宽的可能是"看起来放宽实际是换了个说法禁" |
| 无法判定 | 🔍 你去查，AI 判不了 |

**不要跳过。** 这 30 分钟是防止封号最划算的投资。

---

### 动作 2 · 选题选择（每天 5 分钟）

**位置**：A05 选题官 → 4-6 个候选 → 你选 1 个

**挑的标准（按优先级）**：

```
1. 我有真实经历可以讲吗          ← 最硬的一条
2. 素材准备度 ≥ 3 分吗
3. 不触禁区吗
4. 目标读者会搜这个词吗
```

**不要挑"看起来能爆"的**，挑"你能写出别人写不出的"。后者才是你唯一的护城河。

---

### 动作 3 · 真实素材补充（每天 10 分钟）

**位置**：写稿之前

**看什么**（这是你唯一的不可替代输入）：

```
□ 这件事具体发生在什么场景？
□ 当时是几月？什么项目？
□ 有没有具体的数字？（时间、金额、次数、型号）
□ 我当时的判断依据是什么？
□ 结果如何？有没有出乎意料的地方？
```

**写法示例**：

```
❌ 很多工厂在打磨环节都存在良率不稳定的问题，影响生产效率。
✅ 上个月在东莞一家做五金件的厂子，他们用机器人打磨三个月，良率从 82% 提到 91%，
   但中间换过一次砂轮——第三次才稳定下来。这个数字是厂里的技术员自己统计的，不是设备商给的。
```

**后一段能过 AI 检测，前一段过不了。** 差别就在这。

## 四、降级触发条件（立即停自动化）

**出现任一情况，立刻降到全手动：**

| 信号 | 判断 | 动作 |
|------|------|------|
| 平台警告 / 内容被限流 | 有内容触规则了 | 停工作流，人工排查，改禁区，修质检官 |
| 质检官连续 3 次误报 | 判断不可信 | 停自动放行，重写约束，重测 |
| 一周内容阅读集体下滑 | 可能是账号问题 | 先查违规历史和账号状态，再查内容 |
| 禁区库一个月没更新 | 规则变了但你不知道 | 全部转手动，先补禁区 |

**降级不是失败。** 是系统在告诉你环境变了。

## 五、人工闸的常见误区

### 误区 1：把人工闸当成"最后看一眼走过场"

**表现**：点开终稿，扫两眼，发布。

**后果**：AI 味的内容被发出去，因为「读一遍说不出来这句话」的检查没做。

**纠正**：读出声。说不出来就是有问题。

### 误区 2：把「我全都要 AI 做」当目标

**表现**：为了证明系统牛，把人工闸全部去掉。

**后果**：一次违规，账号没了，前期投入清零。

**纠正**：**自动化的目标不是"无人"，是"无人做重复劳动"。** 选题、判断、承诺这三件事永远留人。

### 误区 3：人工闸变人工海

**表现**：什么都自己干，系统建了不用。

**后果**：比不用系统还累。

**纠正**：判断标准——**这个动作如果做 100 次，你会烦吗？** 会烦的（改稿、排版、格式适配、素材整理）→ 交给 AI。不会烦的（判断、承诺、方向）→ 自己做。

### 误区 4：因为一次误判就全盘否定

**表现**：质检官误报 3 次，觉得 AI 不行，全改手动。

**后果**：效率回到原点，但真问题（分段切碎）没解决。

**纠正**：误报先查分段和约束，**修完再评估**。一次误报是 bug，不是方向问题。

## 六、每月一次：人工闸有效性复盘

问自己四个问题：

| 问题 | 答案说明什么 |
|------|------------|
| 这个月我在人工闸上花了多少时间？ | 趋势是上升还是下降 |
| 有没有本该被拦住但没拦住的？ | 禁区库或质检官的漏洞 |
| 有没有不必要的拦截？ | 误报，约束写太死 |
| 我在人工闸上做的判断，事后看对吗？ | 判断力是否在提升 |

**如果"事后看对"的比例低于 70%，不是你不行，是判断标准没写下来。** 把你的判断依据写进禁区清单和质检标准库，下次就有依据了。

## 七、一页速查

```
每篇：终稿确认（3min）· AI声明勾选（10s）· 对外消息确认
每天：选题选择（5min）· 真实素材补充（10min）
每周：禁区审阅（30min）
每月：人工闸有效性复盘（20min）

永久不可下调：终稿确认 · AI声明 · 对外消息（涉金额/承诺/退款）

降级触发：平台警告 / 质检官连续误报 / 一周没量 / 禁区一个月没更新
```
