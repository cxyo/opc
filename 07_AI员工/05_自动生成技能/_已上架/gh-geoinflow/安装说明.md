# 信息采集员 · 安装说明

## 适用客户端

- 腾讯 QClaw（小龙虾）
- OpenClaw
- 小龙虾 AI（Web / iOS）

## 安装步骤

1. 下载并解压本技能包
2. 放进技能目录（各客户端路径不同，见下方说明）
3. 重启客户端

## 前置条件（**缺一个都装不上**）

- 原项目 yaojingang/GEOInflow 的运行环境与依赖
- 需要的账号、API Key 或本地服务

## 常见装不上的原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示找不到命令 | 依赖没装 | 按原项目 README 装依赖 |
| 提示缺凭据 | 没配 Key | 按原项目 README 配好 |
| 装上了但跑不出结果 | 上游接口变了 | 打开原项目 issue 找维护者 |
