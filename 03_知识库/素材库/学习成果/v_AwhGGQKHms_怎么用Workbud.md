## 主要内容

WorkBuddy 起号 Skill 合集内容：真人出镜 + 5 个 Skill 清单环绕的爆款封面结构。
封面实拍要素：深蓝科技底 + 顶部三行大字（用WorkBuddy/做爆款视频/必装5个Skill，
「5 个」黄色最大）+ 5 张绿色发光卡片环绕（①选题策划 ②视频拆解 ③文案生成
④真人评估 ⑤内容预检）+ 底部真人半身手托图标竖大拇指。
数据：赞 949 / 藏 3463 / 转 1.4万 / 藏赞比 3.65（本批第一）。

## 值得借鉴的点

**「N 个 Skill 清单」这个内容形态，用户可以直接做自己的版本。**

原视频藏 3463 / 赞 949 = **藏/赞 3.65，本批第一**。
转发 1.4 万，转/赞 14.75，在本批也排前列。

值得抄的四点：
1. **数字口径前置且最大字号**。「5 个」用黄色放到最大，
   比「WorkBuddy」「爆款视频」都醒目 —— 先给数字，再给对象。
2. **每个 Skill 用「四字动宾结构」命名**：选题策划 / 视频拆解 / 文案生成 /
   真人评估 / 内容预检。四个字、动宾开头、看一眼就知道干什么。
   → **本系统的 24 个岗位本来就是这个命名法**（A01 安全官、A02 选题…），
   天然可以套这个模板。
3. **真人出镜 + 手托产品图标 + 竖大拇指**，
   在一堆 AI 生成封面里形成「有人在用」的信任差。
4. **「装」字承担了承诺**：必装 5 个 → 装完就能做爆款。
   隐含了「装完就能用」的确定性。

**「81 万播放」这个数字放在标题里而不是封面里**，
说明作者知道：数字负责点击，封面负责给理由。

## 用在哪 · 什么效果

**已落地：封面模板 T8「Skill 清单环绕型」+ 公式 D 数据点补充**

1. **新增封面模板 T8**（`08_可运行系统/staff/title_rules.py`）
   - 布局：深色科技底 + 顶部三行大字（数字口径用强调色放到最大字号）
     + N 张发光小卡片环绕（编号 + 图标 + 四字标题）+ 真人出镜位
   - for_us：「我的 24 个 AI 岗位，装一个网页控制台就够」——
     直接用本系统真实的岗位数做规模数字

2. **公式 D 补充实测数据点**：藏/赞 3.65 证明
   「工具清单」类内容的收藏意图远高于点赞 —— 这在标题公式表里
   是一条**新的判据**：做清单型内容时，藏/赞比转/赞更能预测传播。

3. **命名法对齐**：本系统的岗位命名（A01 安全官 / A02 选题策划…）
   本身就是「编号 + 动宾四字」结构，与封面卡片的命名规范一致，
   可直接出图不需要改词。

**用户自己做的话**：手上已有 4 个已装技能
（ai-content-studio / browser-automation-cdp / lixinger / 一人ai公司），
加上 24 个岗位，可以出一条「我起号只装这 N 个」的对照内容。
