## 值得借鉴的点

**这是本批「工具清单」类内容的最完整范式，可以直接照着做自己的版本。**

藏 203 / 赞 45 = **藏赞比 4.51，本批第一**；转 849 / 赞 45 = 转/赞 18.87。

值得抄的五点：
1. **标题用「真正能」**。
   「真正」两个字是在**对整个品类做筛选声明** ——
   暗示「外面那些不能真搞钱，我筛过了」。
   比「8 个推荐库」有效得多。
2. **每行 = 英文名 + 一句中文用途**。
   英文名让人能搜到，中文用途让人看懂为什么要它。
   只给英文名的清单，读者收藏了也不会用。
3. **「实测整理」四个字**。
   有筛选动作 = 有可信度。没说是「整理」还是「实测」，差别巨大。
4. **编号 01~08 + 每行不同颜色的图标**。
   编号让人知道有尽头（不会翻页翻不完），颜色区分行。
5. **手写便签做情绪层**。
   「真能赚钱！」这种手写体是**人味**，
   在一堆规整排版里反而最抓眼。

**清单行的中文用途写法**可以直接套到本系统：
库名 = 岗位代号（A01 安全官 / A07 情报官…），
中文用途 = 一句话职责。24 个岗位天然就是一张 24 行的表。

## 用在哪 · 什么效果

**已落地：封面模板 T10「编号清单型」+ 清单行的中文用途写法**

1. **新增封面模板 T10**（`staff/title_rules.py`）
   - 布局：顶部大字 + 标题里加筛选声明词（真正/实测/筛过）+ N 行编号清单
     （每行：编号 + 图标 + 名称 + **一行中文用途**）+ 手写便签情绪层 + 底部收藏标签
   - fit：**收藏型内容，本批藏赞比第一（4.51）**
   - for_us：「24 个 AI 岗位，一个网页控制台全装下」——
     每行写：岗位代号 + 一句话职责。

2. **清单行规范已写进模板**：**英文/代号 + 一句中文用途，缺一不可**。
   只给名称的清单不会被用 —— 这是本条最实用的细节。

3. **筛选声明词规则**：「真正 / 实测 / 整理」这类词要出现在标题里，
   它把「信息罗列」变成「替读者做过筛选」，是收藏率的关键差异。

4. **编号清单的尽头感**：N 是有限数字，观众知道翻完就结束 ——
   对应公式 D 的规模数字，但用在清单内部。
