# 一人公司能力框架 · 六大能力

> 用途：诊断"我现在卡在哪一环"，决定下一步该补什么。
> 来源：阿猫《一人公司》（人民邮电出版社，2024）全书框架 + 本项目实践映射。
> 一句话定位：**帮想用 AI 提效的个人和企业，把复杂的 AI 变成拿来就能用的方法、资料和系统。**

---

## 核心公式

```
自媒体收入 = 产品价格 ×（私域数量 × 购买率）× 推出产品的数量
```

**三个提升杠杆**：好友数量、购买率、产品数量。

**关键推论**：哪怕**零新增流量**，只要私域够大、购买率稳定，也能持续赚钱。
这是私域相对公域的根本优势——公域一停更，变现能力立刻衰减。

## ① 商业认知

**三句话**：
- 这个时代谁能满足他人需求，谁就能赚到钱
- 一人公司最核心的理念是：**低成本、小规模和商业闭环**
- 能满足他人需求的服务，就是你的产品

**"把自己当成一家公司经营"的四个动作**：
1. 把自己当成公司主理人——有产品、有客户、有收入、有成本
2. 拥有自己的"生产资料"（知识库、提示词、工作流、案例库）
3. 建立个人 IP，把流量沉淀在自己手里
4. 主动链接销售与传播能力，缺什么补什么

**认知陷阱**：很多人走不通，是因为被专业局限住了，陷入"手里拿着锤子，看什么都像钉子"。
AI 提效这个方向最大的机会在于——**它是横向能力，可以叠加到你已有的任何专业上**。

> **本项目的优势**：你是"工业机器人编程 + AI 提效"双背景。
> 纯 AI 博主讲工具，你讲**工具怎么在真实产线上落地**——这是不可复制的差异点。

## ② 流量能力

**公域 vs 私域**（一句话区别）：

| | 公域 | 私域 |
|--|------|------|
| 本质 | 一次性流量 | **可多次链接**的流量 |
| 比喻 | 顺手在陌生超市买了包子 | 每天路过楼下的老超市 |
| 复购率 | 低 | 高 |
| 风险 | 平台规则随时变、停更即衰减 | 几乎为零 |
| 成本 | 每次触达都要付费 | 触达免费 |

**平台流量难度排序**（易→难）：
```
微信群 > 知识星球 > 公众号 > 小红书 > 抖音
```
→ 新手从微信群和知识星球起步，**把别人的私域当成自己的公域**。

**私域三阶段获取好友**：
1. 主动加（欣赏/请教/背书 三个理由）
2. 贡献价值被加（帮群主答问题/夸奖/输出优质/赠资料）
3. 一出场就被加（优化自我介绍：职业+资源+成绩）

**私域三坑**：只卖低价不敢卖高价 / 产品与定位不匹配 / 缺少铁杆粉丝连接路径（没有群）。

详见：`私域踩坑与产品配比.md`

## ③ 产品能力

**核心定义**：
> **产品不是堆积的知识，而是一套解决方案。**

**能力→产品 的视角切换**：
> 从"我擅长什么"变成"**用户能从我这里得到什么**"。

**能力产品化四步**：积累能力 → 展示能力 → 提炼共性 → 设计产品

**产品形式四种**：咨询（交付思路）/ 课程（交付标准方案）/ 训练营（帮你用好方法）/ 社群（人群聚集）
**决策三维度**：标准化程度、投入产出比、规模化

**产品四层价值**：功能价值 → 节约时间价值 → 情绪价值 → 信息差价值（越往上越有壁垒，但信息差有保质期）

**产品体系五特点**：完整性、层次性、互补性、可拓性、差异化
**没有产品体系的三个后果**：承诺太多难出新品 / 交付困难精力被占光 / 没有层级筛不出不同需求的用户

**起步节奏建议**：
1. 先分销别人的产品，验证私域流量价值，练销售能力
2. 分销赚到**超过 1 万**时，再做一个"轻交付"产品
3. **轻交付**= 每天占用时间 < 可支配时间的 25%
4. 等有 100 个铁杆粉丝，开始适当收费

详见：`产品设计决策表.md`、`资料包价值设计卡.md`

## ④ 营销能力

**五个模块**：

| 模块 | 核心 |
|------|------|
| 心理关卡 | 敢于"豁出去"就是红利；把推广变成"安利" |
| 价值输出 | 打造一个**干货满满**的朋友圈，内容必须与产品匹配 |
| 促单营销 | 晒单 / 晒进步 / 晒反馈 / 晒交付 |
| 活动营销 | 天然（节日）/ 主动（自造节点）/ 借势（追热点） |
| 裂变营销 | 群发售七步法 |

**两个关键数字**：
- 朋友圈打开率约 5% → 1000 好友约 50 人看到 → **一个产品至少发 10 次**
- 60%~80% 的销售额来自特殊节点（节假日/自造活动/热点）

**爆款不重样原则**：同一个卖点换角度讲，用户每次看到同一产品但有信息增量。同一文案只在两种情况重复：转化极好需要复投、活动最后一天（紧迫感本身是最好的文案）。

详见：`私域促单四式.md`

## ⑤ 生态能力

- 构建生态，十倍赋能
- 找到自己的生态位
- 用互推打造人际关系生态
- 合作思维搭建社群生态
- 一人公司的终极目标：生态圈

**起步时机**：**有第一批用户之后**。资源互换是双向的——先帮别人，别人才会在你需要时出手。

## ⑥ IP 能力

- 个人IP的机会与价值
- 尽早完成 IP 商业化
- 用内容打造人设
- 从身份（ID）到个人品牌（IP）的转变
- 持续打造盈利的 IP

**内容即人设**：每篇内容都在告诉用户"我是谁、我是干什么的、我能不能信"。
所有推广最终都是在推广你的个人品牌。

## 战略提醒

**基本盘 + 热点**：
> 任何公司都有基本盘（核心业务）。遇到 AI 这种十年一遇的热点，也要抢占——热点带动基本盘发展得更好。
> 作者本人当时不懂 AI，但做了个 AI 社群，卖了 2000 多份，是当时最火的产品。靠的是：①找到懂 AI 的朋友合作拔高质量 ②每天读 AI 内容在社群里分享。
> **"什么火就做什么"**（前提：能快速学习 + 有交付能力）。

**失败是必经之路**：
> 做自己产品的失败概率接近 100%。没关系——虚拟产品只投入时间，可以尽情试错。
> 失败过程中会倒逼你学：怎么做出好产品 → 怎么写文案 → 怎么定价 → 怎么优化。
