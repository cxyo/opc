## 为什么要单独拆一份

《禁区清单_平台红线》管的是**"你在小红书/抖音发一条内容时不能写什么"**——标题党、擦边、主图极限词、私信导流。

而我们卖的是 **Skill / Agent / SaaS 商品**，那是**"这个软件本身能不能做"**。这两件事的判定逻辑完全不同：

| | 内容发布域 | 产品行为域（本清单） |
|---|---|---|
| 判定对象 | 一条笔记/一个视频/一张主图 | 一个可交付的软件包 |
| 典型风险 | 标题夸大、擦边、诱导分享 | 洗稿工具、破解外挂、去标识服务、批量外呼 |
| 后果 | 限流 / 删文 / 封号 | 封号 + **法律责任（罚款、刑责）** |
| 谁承担 | 发布者 | **工具提供方**（《AI生成合成内容标识办法》明确"不得为他人实施上述行为提供工具或服务"） |

**早先的审核为什么把合格包判成 0 分**：拿内容发布域的条款去扫产品文档，`## 绝对禁止` 这个小节标题里的"绝对"被判成"抖音标题党"，`不写「保证」「100%」` 里的"100%"被判成"淘宝极限词"——**范畴错配**。

现在规则是：

```
扫 Skill / Agent 商品  → 只用本清单（product 域），publish 域条款一律不阻断
扫 要发到平台的内容    → 只用《平台红线》对应平台条款（publish 域）
```

## 四、质检官使用说明（与平台红线共用流程）

```
1. 扫 Skill / Agent / SaaS 商品 → 只读本清单（product 域）
2. 扫要发布到平台的内容        → 只读《平台红线》对应平台（publish 域）
3. 命中 🔴 红线 → 中止，不进 _已上架
4. 命中 🟡 灰区 → 转人工确认，商品留在 _待审
5. 否定语境不算命中：
   「不写「保证」」「不刷量」「## 绝对禁止」这类
   **我们自己写的禁止条款**，是合规声明，不是违规。
   判定关键词命中 ≠ 一定违规 —— 语义优先于关键词。
```
