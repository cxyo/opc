## 一、怎么启动

**最简单：双击 `03_启动控制台.bat`**

浏览器会自动打开 http://127.0.0.1:8899/ 。

**这个窗口要一直开着** —— 它是派活队列的执行器，关了订单就没人执行了。

也可以在 `08_可运行系统` 目录执行：

```bat
python run.py console
```

### 模型调用走哪条路

打开「📊 概览」，最上面有一块「🔌 模型调用通道」，会直接告诉你：

| 显示 | 含义 | 出问题怎么办 |
|---|---|---|
| 绿色「网关」+ 模型网关 new-api | 走本机 :3001 网关，加新模型只改网关 | 网关容器要开着：`docker ps` 看 `ai-hub-new-api` 在不在 |
| 绿色「直连」+ api.deepseek.com | 直连模型厂商 | 网关挂了会自动切到这一条更稳 |
| 红色「未配置」 | 没有 API Key | 去「⚙️ 系统管理」填，或改 `config/config.json` |

**当前状态**：已接入网关，通道 `deepseek-flash` / `deepseek-v4-pro` 都映射好了，
工程侧不需要改任何模型名。

**想临时切回直连**（网关出问题时）：
```bash
cp config/config.json.bak_before_gateway config/config.json
# 然后重启控制台
```

## 三、第一次使用顺序（很重要）

### 第 1 步：填人设档案（5 分钟）

去「👤 人设档案」，至少填这三块：

- **人设** → 你是谁、你的专业领域、你明确不做什么
- **账号定位** → 给谁看、解决什么问题、凭什么是你
- **经历库** → 你的真实故事、具体数据、踩过的坑

**为什么必须填**：AI 写出来像不像你，全看这个。
档案是空的，AI 只能用通用套话，写出来一眼假。
填完之后所有 23 个员工立即生效，不用改代码。

### 第 2 步：跑一次一键成稿

去「⚡ 一键成稿」→ 点「开始跑」→ 等 4 分钟左右。

产出包括：

- 8 个步骤的 Markdown 文件
- 1 张封面图
- 8 张图卡
- 1 个 MP4 短视频
- 1 份公众号排版稿（HTML）
- 1 份发布指引

### 第 3 步：去产出台读一遍，改完再发

去「📁 产出台」→ 点开 `7_去AI味定稿.md` → 直接在文本框里改 → 点「保存修改」。

不满意就点「🔁 让 AI 返工」，写清楚哪里不对，AI 在原文基础上改。

### 第 4 步：发出去

点「📦 生成发布包」→ 打开生成的 `公众号排版稿.html` → 全选复制 → 粘到公众号后台。

## 四、各个按钮干什么

### 派活台
| 按钮 | 作用 |
|---|---|
| 下发指令 | 写到队列，后台 worker 立刻执行 |
| 用示例指令 | 自动填该岗位的建议指令 |

**模型档位怎么选**（影响花费）：

| 档位 | 模型 | 用途 | 相对花费 |
|---|---|---|---|
| `scan` | flash | 查资料、列清单 | 最低 |
| `create` | flash | 写稿、改稿 | 低 |
| `judge_econ` | flash+思考 | 质检（默认） | 中 |
| `judge` | v4-pro | 重要质检 | 最高 |

### 产出台
| 按钮 | 作用 | 花不花钱 |
|---|---|---|
| 保存修改 | 人工直接改，落盘+备份+留痕 | 不花 |
| 🎨 配图配视频 | 出封面、图卡、MP4 | 不花（本地渲染） |
| 📦 生成发布包 | 公众号排版稿 + 封面 + 图卡 | 不花 |
| 📢 推到公众号草稿箱 | 真推到后台草稿 | 不花（但需 appid/secret） |
| 🔁 让 AI 返工 | AI 按你的意见重写 | 花（走模型） |

### 规划师
| 按钮 | 作用 |
|---|---|
| 开始巡检 | 扫全盘，找出命名不规范、空目录、过期文件（只读） |
| 生成整理方案 | 出预览清单，**不动文件** |
| 确认执行 | 按方案执行；删除只移到回收区，不真删 |
| 生成项目索引 | 刷新 `01_项目索引.md` |

### 系统管理
| 按钮 | 作用 | 安全性 |
|---|---|---|
| 初始化工程 | 补齐缺失的目录和文件 | 幂等，不覆盖已有 |
| 备份成 zip | 打包产出+档案+日志 | 安全，config 已脱敏 |
| 导出数据 | 导出 JSON（可迁移） | 安全 |
| 导入数据 | 从 JSON 恢复 | 合并模式，不覆盖 |
| 恢复默认状态 | 重置档案和队列 | **产出保留**（需确认） |

## 五、目录规范（规划师的八条硬规则）

1. 目录名禁止日期数字（`20260101_产出` 不行）
2. 文件名禁止日期数字
3. 目录用 `编号_中文名`（`04_产出`）
4. 空目录必须清理
5. 备份文件每组只留最近 3 份
6. 过期中间产物进 `归档区/`，不直接删
7. 任何删除/重命名前先给预览
8. 产出目录带类型前缀：`文章_XXX` / `数据_XXX` / `视觉素材` / `发布包`
   同名目录已存在时加序号 `_2`，绝不覆盖旧产出

违反规则的会被巡检标为「高危」，整理方案会给出建议改名。

> 当前巡检结果：**0 个问题**（31 个目录 / 127 个文件，全部合规）。

## 六、常见问题

**Q：点了按钮没反应？**
A：看控制台窗口还在不在。关了就重启 `python run.py console`。

**Q：文章写出来像 AI 写的？**
A：99% 是人设档案没填。回「👤 人设档案」把定位和经历填了。

**Q：视频没生成？**
A：需要 ffmpeg。去「⚙️ 系统管理」看「视频 ffmpeg」是不是「就绪」。
本工程已自带 ffmpeg（vendor 目录），正常情况都能生成。

**Q：公众号推不进去？**
A：三个可能：① 没填 appid/secret；② 公众号不是认证号；
③ 没把你的公网 IP 加进「IP 白名单」。
实在不行就用「📦 生成发布包」手动粘贴，一样能发。

**Q：想同时跑多个任务？**
A：派活台可以连着下几单，队列会依次执行。
一键成稿建议一次跑一个，避免同时抢 token 预算。

**Q：产出文件找不到？**
A：① 顶部搜索框直接搜；② 「🗂️ 规划师」生成项目索引；③ 「📁 产出台」左侧有筛选框。
