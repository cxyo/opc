🧾 账单对账

    
本地台账和模型平台账单对不上是常事。先说清两边各是什么口径，再看差在哪天。

    

      

        
本项目台账（data/logs/telemetry.jsonl）

        

          只统计经过本控制台的每一次调用，精确到岗位、任务、字数、花费。

          口径：token = prompt + completion（含缓存命中），与平台一致。
        

        

      

      

        
模型平台账单（如 DeepSeek 用量页）

        

          按 API Key 账号级 统计，包含所有用这把 Key 的工具：

          Docker 里的 hermes-agent、new-api 网关、一次性调试脚本、其它项目……

          所以平台数 > 本地台账数是正常的，差额＝本项目之外的调用。
