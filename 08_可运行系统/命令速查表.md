## 三个最该常用的（说人话）

### `funnel` —— 你的体检表

```
货 → 引流 → 试 → 成交 → 留
```

读系统里的真实数据（发布日志、SKU、禁区、货架页），指出断在哪一环，
并给一条**现在就能敲的命令**。不知道该干什么的时候，先跑它。

### `demo` —— 你的成交入口

给潜在客户一段**他自己的文案**，生成：
- 违规 / AI味 / 错误 三合一体检报告
- 逐条改写示范

客户看见自己的问题，才会付钱解决。产物打包在 `data/outputs/演示包/`，
可以直接发给他。

> ⚠️ 预检命中 0 条不代表没问题。预检只查有明确关键词的条目
> （诱导分享/谣言等），「最强/第一/100%承诺」这类绝对化用语靠质检官独立判断。


### `radar` —— 你的情报过滤器

外部视频、教程、工具推荐进来之后，别一条条看。
`radar` 把它们归成 7 类，每类直接告诉你：

```
✓ 可抄什么   ✗ 不抄什么（附红线依据）   → 现在就做哪一件事
```

最后只输出 **3 件该做的事**，其余全部归档观察。
这是防止你被几十条视频带偏的工具。

## 三种模型档位

> ⚠️ DeepSeek 已于 2026-07-24 弃用 `deepseek-chat` / `deepseek-reasoner` 旧模型名。
> 现在用的是 `deepseek-flash`（V4.1-Flash）和 `deepseek-v4-pro`。

| 档位 | 模型 | 思考模式 | 用于 |
|------|------|---------|------|
| `scan` | deepseek-flash | 关 | 采集、扫描、检索 |
| `create` | deepseek-flash | 关 | 撰写、改写、生成 |
| `judge` | deepseek-v4-pro | 开 | 质检、合规判定（准但慢且贵） |

**质检官三档可切换**（改 `config.json` 的 `judge_tier`）：

| 档位 | 模型 | 单次费用 | 什么时候用 |
|------|------|---------|-----------|
| `judge` | v4-pro + 思考 | ¥0.0799 | 最终发布前的终审 |
| `judge_econ` | flash + 思考 | ¥0.0217 | **默认**，日常够用 |
| `judge_fast` | flash 不思考 | ¥0.0157 | 先跑通流程 |

## 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| `❌ 余额不足` | DeepSeek 账户没充值 | platform.deepseek.com 充值 |
| `❌ 密钥无效` | config.json 里 key 不完整 | 重新粘一遍，别带空格 |
| `❌ model not found` | 用了旧模型名 | 改成 `deepseek-flash` |
| 输出是「[模拟模式]」 | 没充值，或 simulate=true | 充值后 `config --set simulate=false` |
| 找不到文件 | 不在 08_可运行系统 目录 | 先 `cd` 过去 |
| 质检官漏判 | 禁区库没手动分段 | 见扣子搭建说明第 4 步 |
| `python` 找不到 | 系统没装 Python | 用上面那个完整路径 |

## 成本参考

> 以 2026-10 官方单价、空闲时段（晚上/周末）为准。高峰时段（工作日 9-12 点、14-18 点）价格翻倍。

| 操作 | token | 费用 |
|------|-------|------|
| 跑一篇文章（8 步完整链路） | 约 69800 | 约 ¥0.12（高峰 ¥0.25） |
| 单独调一个员工 | 4000-12000 | 约 ¥0.005-0.02 |
| 单独质检一篇 | 约 11600 | 约 ¥0.022（judge 档 ¥0.08） |
| 生成商品详情页（2 步） | 约 18800 | 约 ¥0.036 |
| 21 个员工各跑一次 | 约 149000 | 约 ¥0.25 |

**先充 20 元最合适**：够跑 160 篇文章（按空闲时段算），即使全按高峰价也够 80 篇。
多余余额不会过期，随时可用。

查实时花费：`run.py usage`
查完整清单：`run.py cost`
