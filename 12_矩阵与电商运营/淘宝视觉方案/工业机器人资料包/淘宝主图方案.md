# 淘宝主图方案 · 工业机器人资料包

产品：工业机器人编程资料包

## 硬参数（照抄就行）

| 项 | 要求 |
|---|---|
| 第 1 张尺寸 | 1200×1200（最低 800×800，比例 1:1） |
| 3:4 竖版 | 750×1000 或 1200×1600 |
| 详情页宽度 | 750px，首屏 750×600 |
| 文件 | JPG/PNG，≤≤3MB，≥72dpi |
| 白底 RGB | RGB(255,255,255) |
| 视频主图 | 9-30 秒，≤20MB，首帧必须与第 1 张主图一致 |

## 5 张图分别干什么

### 第 1 张 · 搜索封面

- **作用**：决定搜索结果里的点击率
- **必须满足**：1:1、≥800×800、主体占 70%+、浅色干净底、文字 ≤10%
- **文案草稿**：

```
打磨工作站力控怎么调
工业机器人编程资料包
```

- **不要**：促销标、二维码、极限词、超过 3 行字

### 第 2 张 · 交付清单

- **作用**：消除「买到手是什么」的疑虑
- **必须满足**：文字可读、不遮挡
- **文案草稿**：

```
① XX（XX）
② XX（XX）
③ XX（XX）
④ 现场调试记录 + 常见故障排查
```

- **不要**：抽象图标堆砌、看不出实物内容

### 第 3 张 · 使用场景

- **作用**：让买家认出「这就是我需要的」
- **必须满足**：场景真实、贴近买家日常
- **文案草稿**：

```
程序结构长这样：
（贴你自己写的脱敏代码或流程图）
```

- **不要**：虚构的客户评价、伪造的对话截图

### 第 4 张 · 信任背书

- **作用**：降低「会不会是骗子」的疑虑
- **必须满足**：可验证、留余地
- **文案草稿**：

```
作者：工业机器人编程工程师
来源：机器人打磨工作站、力控、PLC 联动真实项目
交付：网盘链接，下单后 10 分钟内可取
售后：淘宝消息，工作日 24 小时内
声明：非官方教程，与厂商无隶属关系
```

- **不要**：伪造检测报告、盗用资质、编造用户数

### 第 5 张 · 白底图

- **作用**：被抓进「猜你喜欢」公域流量池
- **必须满足**：RGB(255,255,255)、无文字/无阴影/无边框/无模特、主体占 70%-80%
- **文案草稿**：

```
（无文字）
```

- **不要**：任何文字、渐变阴影、边框、模特

## 全局禁止项

- **text_area**：主图文字面积 ≤10%-20%，移动端不超过 3 行
- **subject_ratio**：主体占画面 70% 以上
- **white_5th**：第 5 张强制纯白底、无文字/无阴影/无边框/无模特，主体占 70%-80%
- **promo**：禁促销标（秒杀/包邮/满减）、禁自定义边框、禁水印、禁二维码
- **extreme**：禁「最/第一/顶级/全网最低/100%/根治」
- **outlink**：禁微信号/二维码/手机号/站外链接
