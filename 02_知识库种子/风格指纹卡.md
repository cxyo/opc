> ⬆️ **升级路径**：把下面语料区的 3 篇文章换成你自己写的原文，再按方法重提取一次，风格会立刻准很多。
>
> 为什么要语料：去AI味的本质是「模仿一个具体的人」。没有语料时只能模仿"一个普通技术博主"的通用样貌——能过检测，但过不了「像不像他」的检验。

## 一、当前生效的默认风格（无语料时的兜底）

### 句长特征
- 平均句长：18-25 字
- 短句占比：40% 以上
- 碎片句：会用 3-8 字的独立成段（"这个坑我踩了三年。"）

### 高频词 / 口头禅
- "说白了"
- "实话说"
- "这里有个坑"
- "别急，先看"
- "我一开始也想错了"
- "你猜怎么着"

### 开头方式
- 80% 用**具体场景或结论**开头，不用"随着 XX 的发展"
- 反例（禁止）："在当今这个 AI 飞速发展的时代..."
- 正例："上周我给一个客户搭内容流水线，第一版全废了。"

### 结尾方式
- 给**一个具体动作**收尾（今天就能做的那种），不用"让我们一起…"
- 不用"总而言之""综上所述"
- 正例："今天花 15 分钟，把定位卡的三个待填项填了。"

### emoji 使用
- 公众号：基本不用（最多 1 个，用在关键提醒）
- 小红书：每条 3-5 个，放段首或段尾做视觉分隔
- 抖音口播稿：不用 emoji，用"停顿""【画面】"标记

### 举例方式
- 优先用**自己踩过的坑**（有具体时间、地点、动作）
- 其次用客户场景（隐去公司名，只说行业）
- **没有真实经历就标【待补】，绝不编造**

### 语气
- 直接、务实，承认不知道
- 不谄媚不推销，读者能感到"这人真干过"
- 允许吐槽行业现象，攻击面是**做法**不是**人**

### 明显不用的表达
- "首先/其次/最后"式罗列
- 排比句堆叠（"不只是……更是……更是……"）
- "赋能""颗粒度""抓手""底层逻辑""闭环""链路""矩阵""护城河"
- "震惊""必看""建议收藏""后悔没早知道"
- 三段式对仗结尾

## 二、升级路径（有语料后按此流程重做）

### 提取方法（一次性动作，10 分钟）

把 3-5 篇你自己写的文章丢给任意大模型，用这段提示词：

```
下面是我自己写的几篇文章。请提取我的写作风格指纹，按以下维度输出，
只描述客观特征，不要夸我：
1. 平均句长 / 最长句 / 最短句
2. 我常用的 5-10 个口头禅或高频词
3. 我常用的开头方式
4. 我常用的结尾方式
5. 我用不用 emoji、用几个、放在哪
6. 我怎么举例（真实经历 / 假设场景 / 数据）
7. 我的语气特征（直接 / 委婉 / 毒舌 / 温和）
8. 我明显不用的表达方式
```

把输出粘到下面「三、我的真实风格指纹」对应位置，覆盖第一节的默认值。

## 三、去AI味改写时的硬约束

1. 核心内容（观点、案例、数据）不能改
2. 改成上面指纹描述的节奏，不是改成"更奇怪"
3. 每处改动必须记录在"改写记录"里
4. 改完必须比原文更自然，否则不如不改
5. **AI 味的判断标准是"这句话我会不会这么写"，不是"够不够口语"**

---

## 四、AI 味自检清单（改写后逐条过）

```
□ 有没有「在当今这个…的时代」式起手？
□ 有没有三句排比？
□ 有没有「不仅…而且…甚至…」？
□ 有没有每段都是"首先/其次/最后"？
□ 有没有出现「赋能/闭环/抓手/底层逻辑」这类词？
□ 开头是不是在讲场景，而不是在讲道理？
□ 结尾是不是给了具体动作，而不是喊口号？
□ 读起来像不像我平时说话？
```
