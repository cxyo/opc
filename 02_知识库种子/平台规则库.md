# 平台规则库

> 上传给 `KB_平台规则`，供「多平台适配改写」Agent 参照。
> 核心原则：**同源不同构**——同一观点，结构和语气完全不同。严禁只改字数和 emoji。

---

## 公众号

- 字数：1500-3000
- 风格：深度、论证完整、建立信任
- 结构：痛点 → 分析 → 方法 → 案例 → 总结+行动号召
- 排版：3-5 句一段，小标题分段，关键句加粗
- 发布：每天 1 篇，早 7-9 点或晚 20-22 点
- 钩子位置：文末，自然植入

### 开头三部曲（决定打开率，公众号开头=标题）

> 来源：知乎《搞定开头：让你的文章打开率翻倍》+《公众号速成·开头5种套路》
> 开头承担三个任务：**决定打开率、决定推送打开、指示核心内容**。

| 顺序 | 手法 | 示例句式 |
|------|------|---------|
| 1 | **说效果** | 全文 XXX 字，这套系统性的方法，别说让你 XXX 了，就是 XXXX 也不话下 |
| 2 | **说过程** | 为了这个问题，我花了 X 的时间，写了 X 的干货 |
| 3 | **说故事** | 这道题一定要我回答，因为我就是靠着 XXXX 从 XXXX 变成现在 XXXXX 的 |

**可叠加**：效果 + 过程叠一句，再补数据佐证（"完整看完的有一半收藏了"）。
**禁忌**：盲目夸大 → 招致反驳和举报。

### 新媒体传播六特征（内容设计的底层约束）

| 特征 | 对内容的要求 |
|------|------------|
| 速度快 | 追热点借力；非热点加快处理效率 |
| 强互动 | 引导互动（评论/分享/**回复关键词**）；维护互动，及时反馈 |
| 无目的性 | 标题让用户半秒看懂；开头给"停下来看的理由" |
| 碎片阅读 | 排版简洁、文字流畅、逻辑清晰、图文音视频结合、保证信息密度 |
| 众媒时代 | 让用户参与内容生产与分发 |
| 社交属性 | 内容帮用户表达观点、展示自我、寻找谈资 |

### 完读率四招

1. 尽量带真实照片/图示
2. 快半步写作（先给结论再展开）
3. 分段提炼重点，善用排版工具
4. 先列叙述顺序（框架先行）

### 排版与审美

- 文字品位：不能太 low，也不能太高逼格
- 排版要美、看着舒服
- 输入源：精品图片网站、时尚杂志、高分电影（少看脑残剧）

## 小红书

### 格式
- 字数：300-800
- 标题：15 字以内，痛点场景化，带数字或对比
- 正文：分点清单式，每点 1-3 句
- **必须有对比表格或清单**（强收藏价值，决定完播和收藏）
- 结尾：引导互动（"你试过哪个？评论区聊聊"）
- 话题标签：3-5 个，选精准不选热门

### 标题公式
- "X个[痛点]的解决方法，第X个绝了"
- "从[状态A]到[状态B]，我做对了X件事"
- "别再[错误做法]了！[正确做法]才是正解"

### 禁止
- 直接缩写公众号长文
- 论文腔
- 超 800 字
- 忘加话题标签

### 发布注意
- 图片 6-9 张，首图决定点击率
- 半自动发布（RPA 有账号风险），定时 + 人工确认

## 抖音

### 格式
- 字数：200-500（1-2 分钟口播）
- 结构：结果前置 → 3 秒钩子 → 核心内容 → 行动号召
- 完全口语化
- 必须附分镜建议（画面/字幕/配乐）

### 脚本结构
```
【0-3秒】钩子：一句话说清这期价值
【3-15秒】痛点共鸣：谁会遇到这个问题
【15-45秒】核心方法：2-3 个要点，每个一句话
【45-60秒】行动号召：关注/评论/主页链接
```

### 禁止
- 书面语
- 开头铺垫（第一句不给价值就划走）
- 超 500 字
- 不给分镜建议

## 三平台关系

| | 公众号 | 小红书 | 抖音 |
|--|--------|--------|------|
| 作用 | 沉淀 + 信任 + 私域入口 | 搜索获客 | 曝光拉新 |
| 深度 | 深 | 浅 | 最浅 |
| 更新频率 | 日更 | 3-5 条/周 | 2-3 条/周 |
| 转化路径 | 文末 → 微信 | 主页/评论 → 微信 | 主页 → 微信 |

**所有平台流量最终导向微信。**不沉淀私域 = 给平台打工。
