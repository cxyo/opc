# 私域促单四式

> 用途：朋友圈/私域日常促单的内容模板库。
> 方法论来源：阿猫《一人公司》第四章第三节。
> 原则：**不重样**。同一个卖点，换角度讲；用户看到的是同一个产品，但每条都有信息增量。

---

## 为什么是"四式"

**交付即营销。** 每完成一个交付动作，就该展示一次。营销次数不够，往往说明交付还不够。

**朋友圈只发一次是不够的。**
> 公众号打开率约 5%，朋友圈打开率也差不多。1000 个好友 = 每次发朋友圈约 50 人能看到。
> 所以：**一个产品在朋友圈至少要发 10 次左右，才能让一半的人看到。**
> 有人骂你，恰恰证明推广到位了——你在筛出目标人群。

**什么时候可以重复发同一段文案？** 只有两种情况：
1. 过去某条文案转化极好 → 重复发到效果衰减为止
2. 活动最后一天 → 紧迫感本身就是最好的文案

---

## 式一：晒单

**做什么**：展示真实成交截图（订单、付款记录）

**为什么有效**：让用户直观看到「原来真的有人为此付费」。心理机制同直播间抢购、线下排队、评论区好评——营造「产品很受欢迎」的氛围。

**怎么写**：
```
昨天有个读者私信我说……
[订单截图]
当时第一反应是：会不会是我定价定高了？
后来想想，能帮到人就行。
```
注意：晒单会引发其他客户微妙的情绪触动——这恰恰容易引发成交。

---

## 式二：晒进步

**做什么**：展示你的成长里程碑

**素材来源**（按项目定制）：
- 赚到第一笔钱
- 写了第 100 篇原创文章
- 粉丝破 1000
- 跑通第一个付费闭环
- 交付了第 50 单
- 第一次有人主动推荐

**为什么有效**：用户买的不只是产品，是**靠近你这个人**。看到你持续成长，会觉得你值得信任。

**怎么写**：
```
做内容第 47 天。
今天把流水线又改了一版，
把「去AI味」的温度从 0.8 调到 0.9。
就这么个小参数，出来的句子明显松了。
```
（这种「具体到参数」的真实细节，比"我今天又进步了"强一百倍）

---

## 式三：晒反馈

**做什么**：展示用户反馈

**为什么有效**：自己说产品好没有说服力，换成用户来说完全不一样。

**没有用户怎么办**：**主动邀请**。挑目标明确的人私聊："这周写个三行反馈给我，我把你那段放进资料包里。" 早期用户的反馈是宝贵的素材。

**怎么写**：
```
昨天收到这样一条反馈：
"照着你的方法改了一遍提示词，
第一次发现 AI 输出的是人话。"
——这种时刻就是我做这个的意义。
```

---

## 式四：晒交付

**做什么**：展示实际交付了什么

**这是最容易被忽略、也最有效的一式。**

**素材来源**：
- 咨询服务的时长 + 过程截图 + 结束反馈
- 资料包交付后的用户产出（他用它做了什么）
- 社群里的答疑现场
- 工作流的运行截图

**为什么有效**：交付是最硬的证明。而且——
> 当你觉得自己的营销动作不够多，很可能不是营销的问题，是**交付还不到位**，要倒逼自己把服务做得更好。

## 朋友圈内容配比（1:3:3:3 原则）

不是每条都是广告。参考配比：

| 类型 | 占比 | 内容 |
|------|------|------|
| 价值输出 | 40% | 专业内容、踩坑复盘、方法分享（**必须与未来要卖的产品相关**） |
| 个人故事 | 25% | 成长经历、所思所想、日常 |
| 促单四式 | 25% | 晒单/晒进步/晒反馈/晒交付 |
| 日常与互动 | 10% | 生活、回复、闲聊 |

**关键**：内容价值必须与产品匹配。健身教练发健身科普 → 未来卖健身课别人不反感。内容与产品不匹配，推广就是「伤粉」。

## 促单文案模板

### 模板 A：效果前置
```
[具体结果]用了[具体时间]，[具体变化]
我把这套流程整理成了[产品名]。
[一句话价值]
```

### 模板 B：过程叙事
```
一开始我也[困难]。
后来发现[关键发现]。
现在[结果]。
整套流程我写成了[产品名]，[价格]。
```

### 模板 C：反常识
```
大部分人以为[常见认知]。
其实[真实情况]。
我踩了[N]次坑才明白。
完整清单在[产品名]里。
```

### 模板 D：稀缺与节点
```
[节日/节点]福利：[具体内容]
仅限 [时间] 前。
[产品名] → [领取方式]
```

## 自查清单

- [ ] 这次朋友圈输出的是价值，不是硬广？
- [ ] 内容与我要卖的产品相关？
- [ ] 有具体数字、时间、细节吗？
- [ ] 这条文案和上一条是同一句吗？（是就重写）
- [ ] 促销时是否同步准备了晒单/反馈素材？
