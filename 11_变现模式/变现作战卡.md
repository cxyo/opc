## 核心判断：你的瓶颈不在流量

先跑一次体检，让数据说话：

```bash
python run.py funnel
```

它会告诉你五段漏斗（货→引流→试→成交→留）里断在哪一环，
每段给完成度、缺口、**和一条现在就能执行的命令**。

**只做它指出来的那一件事。** 不要五段一起补。

## 段一 · 货 —— 有没有能卖的东西

### 陈灏怎么说

> 「你没必要等到自己研究出一个新东西，才敢开始收钱。」

> 「如果只是教一次工具，就按课收费；如果要进公司改工作方式，就按项目和服务范围报价。
> 价格拉开，交付也得跟着拉开。」

### 你的现状

11 款 SKU 已建好（`run.py shop` 可看），禁区 71 条，交付形态清晰。
**这一段基本达标，不要再扩 SKU。**

### 一个补充判断

陈灏的课程体系里有个阶梯，你直接对标：

| 他的层级 | 价格 | 你的对应 |
|---|---|---|
| 公开课 | 免费 | 引流区 3 样（岗位说明书/流水线/避坑清单） |
| 入门产品 | ¥39.9-199 | 资料包 ¥49、选题库 ¥199 |
| 实操课 | ¥1000-3000 | ⚠️ **空缺** |
| 定制/陪跑 | ¥5万-10万 | 企业咨询 ¥2000 起（价格偏低） |

**两个空缺：**

**① 中间层缺一档。** 你的服务区全是"代做"（按次），没有"教你自己跑起来"的档。
补一个 **¥299「流水线搭建陪跑」**：我帮你把你自己的业务装进这套系统，
交付物是**你自己的提示词 + 你的知识库 + 一份操作手册**。

这一档的价值：
- 比 ¥199 代做**更便宜**（客户心理上是"教我"不是"替我做"）
- 但比代做**更值钱**（他以后每篇都省时间，会回来买月费）
- **交付边际成本几乎为零**——你跑的是现成系统，只是换了他的业务数据

**② 企业咨询定价偏低。** 你写着「¥2000 起」，但你交付的是
"诊断 + 落地方案 + 2小时答疑"，这在市场上一致定价 5000-10000。
**你不是在卖时间，是在卖"我知道 AI 建议在产线上为什么行不通"。**
先按 ¥2000 卖 1 单，拿到案例后涨到 ¥5000。

```bash
python run.py shop --export   # 看当前 11 款 SKU 和定价
```

## 段二 · 引流 —— 有没有持续产出

### 陈灏怎么说

> 「我后来换成『普通人怎么用 Codex』『不会写代码怎样做产品』，
> 读者一下就知道跟自己有什么关系。同样讲 AI，一个标题像行业报告，
> 一个能让人今晚就动手，流量差得非常远。」

> 「曝光高、主页访问低，先看标题和开头有没有把人带进来；
> 主页访问多、关注少，就去改简介和置顶。」

### 你的现状

8 步链路能出稿，定位卡和风格卡已填。**但选题池是空的，发布数据也没回填。**

### 三个动作

**① 选题池从 0 到 30**

```bash
python run.py ask A05 "根据我的账号定位卡，生成 30 个选题，每个带四维评分"
```
然后存成 `data/state/选题池.csv`（表头：标题,状态,四维评分）。
A05 每次跑都会读它，避免重复。

**② 内容标题改成"能让人今晚就动手"**

你的定位是「帮想用AI提效的人把AI变成能用的方法」。
对照改写：

| ❌ 行业报告式 | ✅ 能动手式 |
|---|---|
| AI 内容生产的技术演进 | 我把一篇文章的产出时间从 3 小时压到 8 分钟 |
| 提示词工程的最佳实践 | 同一个模型，换个问法，垃圾变可用 |
| 知识库搭建方法论 | 我的知识库从 0 到能用，只花了一个周末 |

**③ 发布后回填数据（这步最容易漏，但漏了整个漏斗就瞎了）**

```bash
# 手动编辑 data/state/publish_log.csv，把阅读/点赞/涨粉/成交填进去
```
不填数据，`funnel` 就判断不出你的内容到底哪篇在卖。

## 段三 · 试 —— 有没有让人白嫖到手的入口

### 陈灏怎么说

> 「成交升维：从『反复说服』到『结果前置』。
> 最高级的成交，从来不是说服，是直接呈现结果。」

> 「美业上传素颜照，AI 立刻生成不同品相的术后效果，
> 用户一眼看见自己变美的样子。」

### 你的现状 ❌ 这是最大缺口

你有 11 款 SKU，但**没有任何一个入口让客户免费拿到真东西**。
客户看你的货架页，看到的是"我有什么"，不是"我能得到什么"。

### 动作：上线"结果前置"演示入口

```bash
# 拿一段示例文案（或客户真实文案的脱敏版）生成演示包
python run.py demo --file 演示用文案.md
```

产出的「演示包」包含：
- 质检报告（违规/AI味/错误三合一）
- 逐条改写示范

**这个包就是你的引流品。** 它的说服力在于：
客户看到的是**他自己的文案**的问题，不是你的服务介绍。

### 把它挂到三个地方

| 位置 | 怎么挂 |
|---|---|
| 货架页引流区 | 加第 4 项：「免费试一下你的文案」+ 一份脱敏演示报告 |
| 朋友圈/群 | 发演示包的正文（不含敏感信息），末尾一句"想试自己的？私信发我" |
| 私信第一句 | 客户问"多少钱"时，不报价，先说"把你的文案发我，我免费给你看一眼" |

### 配套：可试问入口（抄智向未来）

智向未来把最想卖的岗位直接开放免费试问。你的等价物：

```bash
python run.py ask A07 "帮我写一篇关于XX的文章"
```
把输出截图/文本贴到货架页或朋友圈，标注"这就是 A07 撰稿官现场跑出来的"。

> **客户不需要理解什么是"智能体"，他只需要看见"这玩意儿真能干活"。**

## 段四 · 成交 —— 有没有明确的付款动作

### 陈灏怎么说

> 「别等下课了突然掏出一份十万元报价。」
> 「课上让他把最费人的那条流程写出来，现场先拆清楚……
> 下课后，你拿这张流程图约一次单独沟通。」

> 「转化话术也要跟着产品变。文章末尾别只写一句『想学的私信我』，
> 写得具体一点：『如果你已经发了十篇内容，还是不知道问题出在哪，
> 把最近三篇和后台数据带来，我现场给你拆标题、开头和选题。』」

### 你的现状

货架页有价格、有联系方式，但 **4 处 `【待填】` 还没填**。

### 动作（今天就能做完）

**① 填完 4 处待填项**
- 微信号
- 公众号名
- 小红书号
- 闲鱼/面包多搜索词

**② 每一款商品后面加一句"怎么买"**

现在是「**获取方式**：加微信领取，或直接看公众号历史文章。」——太模糊。
改成：「加微信，备注『流水线』，我把 ZIP 发你，48小时内。」

**③ 写清楚"不满意怎么办"**

你资料包详情页里已经写了"不适合谁"，这是对的。
**货架页也要有**——降低退款率，也降低客户的疑虑成本。

**④ 私聊话术按客户类型分三种**

| 客户说 | 你回 |
|---|---|
| "多少钱？" | 不报价。先说："把你的文案发我，我免费给你看一眼问题在哪。" |
| "能学吗？我不会写代码" | "能。整套东西是复制粘贴，不需要写代码。你要花 1-2 天跑通第一遍。" |
| "太贵了" | "资料包 49，够你跑一个月。跑完觉得没用，就当买了张彩票。" |

## 段五 · 留 —— 有没有复购和转介绍

### 陈灏怎么说

> 「有个 99 元的社群，已经进了 100 多人，快接近 200 人，
> 这就是内容带来的直接收入。」
> 「让用户看哪篇有人愿意转、哪篇评论里出现更多新问题。」

### 你的现状

有 ¥99/年会员，但**没有把"一次成交"转成"月费"的路径**。

### 动作：把代做服务改写成按月

这是本轮**最能提升收入结构**的一个改动：

| 现在 | 改成 |
|---|---|
| 公众号长文代写 ¥199/篇 | 内容代做月卡 **¥699/月**（含 4 篇公众号 + 不限次体检） |
| 发布前合规体检 ¥29/次 | 保留，但主推 **¥199/月不限次** |
| 短视频口播稿 ¥99/条 | 会员权益 |

**为什么这是对的：**

- **客户视角**：一个月要发 4-8 篇，按次买要 ¥800-1600。¥699 明显划算。
- **你的视角**：单次代做成本 ¥0.12，4 篇成本 ¥0.48。**你卖的是判断，不是算力。**
- **行为改变**：按月买的人会**主动把选题发给你**（因为他已经付了钱），
  你的内容生产从"憋选题"变成"接需求"。

**会员权益也要改**：现在写的是"提示词库更新""优先答疑"——太虚。
改成可量化的：
- 每月 1 次免费合规体检（单次值 ¥29）
- 每月 1 次选题库定制（单次值 ¥199）
- 专属问答（48 小时内回）
