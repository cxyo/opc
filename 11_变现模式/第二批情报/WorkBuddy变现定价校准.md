## 三、诊断

**结论：你的定价偏高了，不是偏低了**

- 现状：22 个技能定价 ¥29-99，均价约 ¥60

- WorkBuddy 官方明确建议「初期设 5 元或 10 元测需求」——因为现阶段买家对一个没听过的技能，决策成本就是几块钱。
- 市场上真实在售的付费 Skill 是 19 元/月 和 29 元买断，不是 99 元。你的 ¥99 档位在平台上属于高价，需要极强的信任背书才卖得动。
- 你还没有案例、没有评价、没有成交记录。**没案例的人不该先卖高价**——这违反了你自己定的「按客户省下的时间定价」原则，因为客户还不知道能不能省。

**但淘宝店和 WorkBuddy 开放平台是两套逻辑，不要混：**

- **淘宝店**：买家搜「机器人编程资料包」带着明确需求来，客单价敏感度低，¥49-199 能卖。因为他要的是「省两天现场调试」，这个价值可感知。
- **WorkBuddy 开放平台**：买家逛市场，没有明确需求，决策成本极低，只能靠低价试水。所以要 ¥5-29。

## 四、方案

**原则：WorkBuddy 开放平台 = 引流位；淘宝店 = 利润位。同一份 Skill 包，两边不同价，不是冲突，是分工。**

### 步骤 1. 先免费上 3 个（不是全部 22 个）　`免费`

选 A10 质检官 / A09 去AI味 / A22 淘宝视觉官。免费的意义不是送，是让平台收录你的技能、让用户先装上、后续再推付费版

### 步骤 2. 付费版用「低价探需求」　`¥9.9`

把 A22 淘宝视觉官挂 ¥9.9 一次性（不是 ¥99）。官方建议 5-10 元起步，你按 9.9 走

### 步骤 3. 观察后台付费人数，再决定涨价　`视数据定`

WorkBuddy 后台能看到「累计付费人数」。如果 9.9 元有人买且转化率 > 1%，再提到 ¥29；如果没人买，说明是价值表达问题不是价格问题

### 步骤 4. 淘宝店维持现有定价，但补案例　`¥49-199`

淘宝 ¥49-199 保留。但必须先有 1-2 个真实成交案例（截图+买家原话），否则再降价也卖不动

**为什么这么走**：

- 9.9 元的付费是一个「筛选器」——它筛出的是真需求，而不是白嫖党。这比免费更能告诉你东西对不对。
- WorkBuddy 月活 2000 万、日活 1300 万，且平台流量在腾讯桌面端产品里，不需要自己找流量。**这是零获客成本的测试场**——比投流划算。
- 你已经在淘宝店有真实的技能交付经验，这个「已跑通过」本身就是平台要求「原创声明」时最硬的底气。

## 落地到代码

WorkBuddy 开放平台的价格和淘宝店价格是**两套**，所以不要直接改 `skill_pack.py` 的 `PRICING`：

```
PRICING（淘宝店用）      ← 保持 ¥29-99 不动
WorkBuddy 开放平台（引流） ← 3 个免费 + A22 挂 ¥9.9
```

上架步骤（官方口径）：

1. 在 WorkBuddy 里把流程让 Agent 转成技能，打包成 zip
2. 传到 `open.workbuddy.cn` 提交审核
3. 审核通过后 → 回到「收入变现」开通收款账户
4. 微信扫码签约 → 发布时选「付费」→ 定 9.9 元

> **第三道门槛最容易被卡**：必须先有 1 个通过审核的技能或专家，才能开通收款。所以先传免费的那 3 个。
