## 一、先纠正一个前提

**你的生意不是"卖资料包"，是"卖技能包"。**

淘宝店首页写着：「500+龙虾技能 · 每天更新一个实用Skill · 微信原生推送 · 一键安装 · 自动发货」。

这说明你已经跑通的是**Skill 商店**模式。而项目里 `07_AI员工/01_Bot提示词/` 的 21 份岗位说明书，
每一份都已经包含「角色 + 职责边界 + 执行流程 + 输出规范 + 降级行为 + 绝对禁止」——
**这就是 SKILL.md 需要的全部内容**，只是格式是给人看的文档，不是给 Agent 装的目录。

所以第一件事不是"想清楚做什么"，而是**把已有的 21 份说明书变成 21 个能上架的技能包**。
这件事已经做完了（见第三节）。

## 二、五个渠道，各干什么

```
                 内容（小红书/抖音）
                        │
                        ▼  种草 → 引导搜索
    ┌───────────────────────────────────┐
    │                                   │
    ▼                                   ▼
淘宝店（主成交）                  闲鱼店（第二成交）
lxzlj.taobao.com                  同一套技能包
    │                                   │
    └─────────┬─────────────────────────┘
              ▼
        公众号 LobsterSkill
        （沉淀 + 售后 + 复购）
```

| 渠道 | 唯一职责 | 不要做 | 频率 |
|------|---------|--------|------|
| **淘宝店** | 成交 + 发货 | 别在上面发内容 | 常态维护商品 |
| **闲鱼店** | 第二成交口 + 引流款 | 别重复铺全部 SKU | 每周上新 1-2 个 |
| **小红书** | 种草引流 | 别做成交（小红书禁站外交易） | 每周 2-3 篇 |
| **抖音** | 演示引流（技能最好拍） | 别做成课程号 | 每周 2-3 条 |
| **公众号** | 装机教程 + 答疑 + 复购 | 别日更（写不过来） | 每周 2 篇 |

**关键判断**：淘宝店首页已经有「微信原生推送」这个卖点，
说明你的买家是**已经装了 QClaw/龙虾的人**。他们不缺工具，缺的是"这个技能具体能帮我干什么"。

所以内容不能讲"AI 有多强"，要讲**"我今天用这个技能省了 40 分钟"**。

## 三、已经做完的：21 个技能包

`05_产品交付/Skill包/` 下，每个岗位一个目录 + 一个 zip：

```
a10-quality-inspector/
├── SKILL.md          ← YAML frontmatter + 完整提示词
├── clawhub.json      ← 元数据 + 定价
├── README.md         ← 市场落地页（适合谁/不适合谁/怎么用/FAQ/售后）
├── 安装说明.md        ← 给买家的一页纸（含"装完不生效=没重启"这个坑）
└── a10-quality-inspector.zip   ← 直接挂淘宝自动发货
```

**21 个技能，定价 ¥29-99，合计 ¥1219**（技能可拆开单卖，也可以做组合包）。

重新生成：

```bash
cd 一人AI公司/07_AI员工/tools
python skill_pack.py            # 全部 21 个
python skill_pack.py A10 A07    # 只重打某几个
python skill_pack.py --list     # 看清单和定价
```

### 三个需要你亲手改的地方

| 位置 | 改什么 | 为什么 |
|------|--------|--------|
| `PRICING` 字典 | 每个技能的定价 | 现在是我按市场猜的，你比我清楚实际能卖多少 |
| `AUDIENCE` 字典 | 「适合谁/不适合谁」 | 这段直接决定转化率，必须是你的真实观察 |
| `EN_SLUG` 字典 | 英文 slug | 已填好，除非你要改品牌命名 |

### 三个必须知道的技术事实

1. **ClawHub 不支持付费技能分成**——官方仓库全是 MIT-0 免费技能。
   你在淘宝自己卖 zip 才是正确路径（也符合"自动发货"的现状）。
2. **装完技能必须重启客户端**，否则 Agent 认不到。99% 的"技能不好用"都是这个原因。
   所以 `安装说明.md` 里已经把它写成加粗提醒。
3. **ClawHub 生态有投毒历史**（ClawHavoc 事件，341 个恶意技能窃取凭证）。
   你上架自己的技能时，README 里主动写清"无脚本执行、纯提示词"反而是信任加分项。

## 四、接下来先做什么，再做什么

### 第一优先（今天，2 小时）—— 把 3 个主推款挂上淘宝

**为什么先做这个**：货已经在你手里躺着，但**没有人知道你卖的是这个**。
淘宝店现在主推"500+技能"，你的 21 个岗位是**垂直、可验证、有售后**的差异化货。

具体动作：
1. 挑 3 个最好上架的（我建议：**A10 质检官 ¥99 / A09 去AI味 ¥59 / A07 撰稿 ¥69**）
   - 理由：这三个是"用了立刻能感觉到差别"的，不需要解释背景
2. 标题带上搜索词，例：
   - `龙虾技能 AI内容质检助手 发稿前查违规 公众号小红书抖音通用`
   - `AI去AI味技能 公众号改写 人话风格 装上即用`
3. 详情页直接用包里生成的 `README.md`，**不要重写**
4. 定价先用 `PRICING` 里的值，观察 7 天再调

### 第二优先（本周，3 小时）—— 三个渠道各发一条"技能演示"

不要写"我做了 21 个技能"这种自夸内容。写**具体场景**：

| 平台 | 内容方向 | 示例标题 |
|------|---------|---------|
| 小红书 | 装机踩坑（真实） | 「龙虾技能装完不生效？99%的人漏了这一步」 |
| 抖音 | 30 秒演示 | 装 A10 → 扔一篇稿子 → 打出违规/AI味/错误三段报告 |
| 公众号 | 装机教程 | 「21 个龙虾技能怎么选：3 分钟对号入座」 |

**为什么是这三条**：小红书已有"截流/获客"类爆款说明这个赛道吃"避坑"内容；
抖音适合演示；公众号做沉淀承接搜索流量。

### 第三优先（下周）—— 打通"技能 → 定制服务"

这是**利润最高的一环，但必须排在前面两步之后**。

理由：卖 ¥99 的技能包，扣掉平台费和售后，单个利润很薄。
但技能装上之后，客户立刻会问"能帮我改一下我的号吗"——**这是 ¥699-2000 的单子**。

具体：
1. 淘宝详情页加一句：「装完还不会用？¥699 帮你配置一次」
2. 公众号开一篇：《装上了但还是不会用？我帮你调一次》
3. 这一步的交付官（A21）已经有现成的流程

### 第四优先（一个月后）—— 复盘砍掉一半

`run.py funnel` 的「留」段需要成交数据才能启动。
有了第一批成交后，按 `09_AI超市模式/选品清单与定价.md` 第六节的复盘表填一遍，
**明确砍掉没人的那 5 个技能**。

## 五、明确不要做的

| 不要做 | 原因 |
|--------|------|
| 同时运营 5 个渠道的日更 | 你一个人。5 个平台各发 1 条/天 = 5 份定制内容，做不到 |

## 六、AI 员工到底是不是自动工作的

**直接回答：目前不是自动的。**

| 层 | 现在是什么状态 | 怎么变 |
|----|--------------|--------|
| **本地 21 个岗位** | 你手动敲 `python run.py today`，它跑完 8 步 | 这是"工作台"，本来就是你指挥它干活 |
| **扣子 3 个 Bot** | 文档写好了，**你还没去建** | 建好后 A03 情报官可每天 08:30/21:00 定时跑，A16 每周一 09:00 |
| **发布** | 全手动 | 官方接口要企业主体；浏览器自动化只能做到"自动填好，你点发布" |
| **真正的自动** | 不存在 | 平台 AI 声明必须人工勾，这道闸是故意留的 |

**为什么不做成全自动**：封号不可逆，出错成本全在你身上。
三道人工闸（终稿确认 / AI 声明勾选 / 对外承诺确认）换来的是"任何一步都能人工接管"。

**但有 3 个岗位可以真的自动**，它们不涉及对外动作：
- A03 情报官 —— 采集、筛选，不发布
- A16 GEO优化官 —— 生成词库和内容规格，不发布
- A01 安全官 —— 比对规则，产出差异表等你确认

这三个就是扣子那 3 个 Bot 的由来。**建它们是你"让 AI 员工自动工作"的唯一现实路径。**
