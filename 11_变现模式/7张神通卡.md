# 7 张神通卡 · 你的「离苦得乐」弹药库

> 来源：陈灏（视频②作者）提出的「神通 = 神奇的结果 + 跑得通的逻辑 + 真实的案例」。
>
> 他的原话：**「你只需要沉淀 7 个核心神通，就能靠 AI 完成无限适配。」**
>
> 这份文件解决你的系统里一个真实的缺口：你的 21 个岗位解决「怎么写」，
> 但没有解决「写什么能打动人」。

---

## 一、什么是神通卡

普通选题 = 一个话题。
**神通卡 = 一个能反复讲的「结果 + 逻辑 + 案例」三件套。**

它不是文章，是**弹药**。同一张神通卡可以：
- 变成一篇公众号长文（结果 → 痛点 → 逻辑 → 案例 → 怎么做）
- 变成一条 60 秒口播稿（只讲结果和痛点）
- 变成一条小红书（只讲案例）
- 变成一个产品卖点（结果就是卖点）
- 变成一个直播选题（你的案例最能撑场）

**这就是「一次沉淀，无限适配」。**

### 三要素的判断标准

| 要素 | 合格线 | 不合格的样子 |
|---|---|---|
| **神奇的结果** | 具体的、可验证的数字或状态变化 | "提升效率"（谁都能说） |
| **跑得通的逻辑** | 别人照着能复现的步骤 | "要善用 AI"（等于没说） |
| **真实的案例** | 你自己或可署名的真实经历 | 网上看来的别人的故事 |

> ⚠️ **重要**：案例必须是你自己的。别人的案例只能当"参照系"，
> 不能当"我的神通"。这条线是 AI 检测和平台合规的共同红线。

## 二、7 张卡的框架

**卡 1 到卡 4 先填**（这四张对应你最真实的资产），卡 5-7 是扩展。

每张卡填完后，在下面写一行「一句话标题」——那就是你以后所有内容的种子。

---

### 🔧 卡 1 · 我把 XX 从 YY 变成了 ZZ

| 项 | 填什么 |
|---|---|
| **结果** | 具体数字或状态变化。例："内容流水线从 6 天搭不出，变成 6 小时跑通" |
| **逻辑** | 3-5 步可复现的步骤，别人照做能出同样结果 |
| **案例** | 你自己的经历：什么时候、为什么、踩了什么坑 |
| 一句话标题 | |

---

### 🔧 卡 2 · 我把「费钱的做法」换成了「不费钱的做法」

| 项 | 填什么 |
|---|---|
| **结果** | 成本对比。例："跑一篇文章的 API 成本从 ¥3.2 降到 ¥0.12" |
| **逻辑** | 换掉了什么、为什么换、怎么换的 |
| **案例** | 你的真实对比数据、踩过的坑 |
| 一句话标题 | |

---

### 🔧 卡 3 · 我原来不信 XX，直到 XX

| 项 | 填什么 |
|---|---|
| **结果** | 认知转变带来的实际变化 |
| **逻辑** | 是什么让你改观的（最好是具体的一件事，不是道理） |
| **案例** | 你从不信到信的转折点 |
| 一句话标题 | |

> 这张卡最容易火。因为**怀疑是读者的默认状态**——你说出"我原来也不信"，他才愿意听下去。

---

### 🔧 卡 4 · 我踩过的坑，你别再踩

| 项 | 填什么 |
|---|---|
| **结果** | 避开了什么损失（时间/钱/账号） |
| **逻辑** | 坑的成因是什么，为什么大多数人都会踩 |
| **案例** | 你真实踩过的，最好有具体数字（"限流 15 天"） |
| 一句话标题 | |

> 你的定位卡里写着"他们给工具清单，我给跑通的参数和踩过的坑"。
> **这张卡就是那句话的具体化。**

---

### 💡 卡 5 · 我怎么帮 XX 解决了 YY

| 项 | 填什么 |
|---|---|
| **结果** | 客户/朋友/同事的问题被解决了，效果可描述 |
| **逻辑** | 你的方法为什么有效（可迁移到别人的场景） |
| **案例** | 真实案例。**必须隐去敏感信息**，但不能编 |
| 一句话标题 | |

> ⚠️ 这张卡最容易踩合规线：
> - 不能承诺效果 → 写"实际交付了什么"，不写"保证你能得到"
> - 不能编案例 → 没有的事就空着，空着比编着安全
> - 涉密信息脱敏 → 客户的敏感数据用"某制造业客户"代替

---

### 💡 卡 6 · 一个反常识的发现

| 项 | 填什么 |
|---|---|
| **结果** | 这个发现改变了什么做法 |
| **逻辑** | 为什么反常识——通常的直觉错在哪 |
| **案例** | 你自己的验证过程 |
| 一句话标题 | |

---

### 💡 卡 7 · 我只做了一件事，结果是 XX

| 项 | 填什么 |
|---|---|
| **结果** | 单点聚焦带来的结果（对比"什么都做"） |
| **逻辑** | 为什么单点比多点更有效 |
| **案例** | 你自己或真实观察到的对比 |
| 一句话标题 | |

## 三、怎么用这些卡

### 填完之后

**Step 1 · 存成知识库**

把填好的 7 张卡存成一个文件，放进：
```
02_知识库种子/神通卡.md
```
（建议一张卡一个二级标题，格式和 `风格指纹卡.md` 保持一致）

**Step 2 · 让撰稿官用上它**

`A07 撰稿官` 现在只读"账号定位卡"和"风格指纹卡"。
把神通卡也加进去，内容质量会有明显变化——因为撰稿官能拿到**具体的数字和案例**，
而不是只有"专业"的形容词。

**Step 3 · 每次出稿优先用神通**

改 `pipeline.py` 的 A07 步骤，加一句：
```
优先从【神通卡】里挑一张最贴合本选题的，用它的案例和数字来写。
没有贴合的就用最接近的一张改写角度。
```

**Step 4 · 一张神通卡 → 五种内容**

```bash
# 1. 长文（完整三件套）
python run.py today --topic "你的选题"

# 2. 口播稿（只讲结果+痛点）
python run.py ask A17 "基于神通卡 X，写一条 60 秒口播稿"

# 3. 小红书（只讲案例）
python run.py ask A11 "基于神通卡 X，出一版小红书"

# 4. 产品卖点（结果就是卖点）
python run.py product --name "商品名"

# 5. 直播选题
python run.py ask A05 "基于这 7 张神通卡，出 10 个直播选题"
```

## 四、填卡时的三条硬规则

### 1. 数字必须是真的

神通卡的全部力量来自"可验证"。
一个假的数字会让这张卡**长期负债**——每次用都在透支信任，而且平台会判虚假宣传。

> 没有数字怎么办？**改成具体的状态描述**。
> "限流 15 天" 是数字；"账号被屏蔽，推荐页完全刷不到自己" 也是数字的具体化。

### 2. 案例必须是你的

网上看到的、课程里学的、同事口述的——都不算。
可以**当参照系引用**（"某某公司的做法是…"），但不能**当自己的神通**。

### 3. 涉及效果的表述走三道人工闸

神通卡会直接变成对外内容，所以：
- 效果承诺 → 必须过 A10 质检官
- AI 声明 → 发布时勾选
- 对外承诺 → 人工确认

**这三个闸不是形式主义，是你的账号能活下来的原因。**
