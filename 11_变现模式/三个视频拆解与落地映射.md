## 二、逐个拆解

### 视频① 智向未来的「AI投手」

**它是什么**

智向未来（中隐会旗下）的产品线叫「**三省六部 AI 经营指挥舱**」，官网 zxwlchat.com：

- **24 个岗位机器人**，其中之一就是"AI投手"
- **2 个岗位**开放免费试问（销售成交、财税诊断）
- **5 级落地路径**：岗位机器人实战课 → 岗位机器人中心（可试问）→ 企业 AI 应用落地课 → 线下私董会 → 三省六部系统（政企/集团本地化部署）

架构本身很直白：

| 层 | 干什么 |
|---|---|
| 中书省 | 战略与规划：年度经营计划、AI 场景地图、部门目标拆解 |
| 门下省 | 审核与风控：合同风险、财税合规、数据安全、流程审核 |
| 尚书省 | 执行与调度：执行排期、部门协同、关键任务推进 |
| 六部 | 销售成交 / 财税经营 / 品牌内容 / 组织人才 / 产品交付 / 合规风控 |

创始团队三人：谭欢（AI技术与商务协同）、饶倍华（财税专业与风险控制）、龙星亮（AI战略与数字化增长）。

**这个视频为什么值得看**

它证明了"**把岗位做成机器人，然后卖岗位**"这条路已经被有资源的公司走通了——而且是用**试问 → 留资 → 承接顾问**的漏斗，不是靠投流硬砸。

**对你意味着什么**

你已经有 21 个岗位。他的 24 个岗位里，你能对标的是"品牌内容部"下的岗位——流量、内容、转化。**但别去跟他的"三省六部"比架构**，那是给集团/政企做的本地化部署，你一个人做不了也不该做。

**你要抄的是两个动作，不是架构：**

1. **"可试问"这一步** —— 他把最想卖的两个岗位直接开放免费试问，客户先玩再留资。
   → 你的系统已经有 `run.py ask A07 "..."`，**这就是你的"试问"，只是还没包装成给客户用的入口**。
2. **岗位说明书带"适合谁/不适合谁"** —— 他的岗位机器人页面明写"适合：销售团队、渠道团队、业务负责人"。你的 SKU 表里已经有这个字段，做对了。

**你不能抄的**：他的护城河是财税专业资质 + 本地化交付团队 + 300+ 企业案例。这三样你一样都没有，抄了也打不过。

### 视频② 陈灏的「AI变现三部曲」

**它是什么**

这是三个视频里**对你最直接有用**的一个，因为它补的是你系统缺的最后一块。

从公开的连麦精华可以确认，陈灏讲变现是三段式：

| 段 | 主题 | 核心命题 |
|---|---|---|
| 一、交付革命 | 跳出"时间换钱"的死循环 | **重 AI 交付 + 轻人工陪伴** |
| 二、流量破局 | 告别"干货自嗨" | 用户要的是**离苦得乐**，不是你的干货船 |
| 三、成交升维 | 从"反复说服"到"结果前置" | **不要说服，要让用户先看见结果** |

三个可迁移的方法：

**① 交付革命：重 AI 交付 + 轻人工陪伴**

他的案例：某亲子教育 IP 原来创始人亲自做年度陪跑，定价 10 万/年，最多接 50 单，天花板 500 万。
改成「10 个数字老师 + 1 个真人班主任」后，定价降到 3 万/年，营收冲到 3000 万。

> **关键不是降价，是把 80% 的标准化交付交给 AI。**你的 21 个岗位正是这 80%。真人只做"情绪陪伴与关键节点把控"——也就是你的三道人工闸。

**② 流量破局：神通 = 神奇的结果 + 跑得通的逻辑 + 真实的案例**

他说只需要沉淀 **7 个核心神通**，就能靠 AI 无限翻译成不同圈层的内容。

**这对你是个缺口。** 你的知识库里有"账号定位卡""风格指纹卡""选题池 30 条"，但**没有一张"神通卡"**。你的 21 个岗位解决"怎么写"，没解决"写什么能打动人"。

**③ 成交升维：结果前置**

> 「最高级的成交，从来不是说服，是直接呈现结果。」

他的做法：美业上传素颜照 → AI 生成术后效果图；保险输入家庭情况 → 生成可交互方案。**让客户先看见"改变之后的自己"，走向你就成了自然而然的选择。**

### 视频③ 小爷Uncle 的「神BOT」

**它是什么**

讲的是 **Grok Bot**（xAI，2026-08-11 推出 beta）以及一个叫 **XYskill** 的东西。

Grok Bot 的机制值得说清楚：

- 每个 Bot 有**自己的云端电脑**（浏览器 + 文件系统 + 终端）
- 用**你自己的登录凭证**登录现有工具（CRM、Gmail、后台），所以能操作那些没有 API 的老系统
- **你演示一遍，它记住步骤存成 routine，之后定时自己跑**
- 多 Bot 可以互相协作（Mac 上叫 Channel，iOS 上叫 Group Chat）
- Beta 阶段，捆绑 SuperGrok / Cursor 付费档

他的核心观点是"一代版本一代神"——2026 下半年三大厂同时收敛到同一个形态：

- xAI → Grok Bot（2026-08-11）
- Microsoft → Scout（企业版）
- Google → Spark（消费者版）
- Meta → Muse（2026-09）
- OpenAI → Dots（2026-09）

**这对你的意义：不是"要不要换工具"，而是"你的系统处在哪个世代"。**

对比一下你的 21 个岗位和 Grok Bot 的差距：

| 能力 | 你的现状 | Grok Bot |
|---|---|---|
| 岗位定义 | ✅ 21 份岗位说明书 | ✅ |
| 知识库 | ✅ 本地 TF-IDF 检索 | ✅ |
| 链路编排 | ✅ 8 步流水线 | ✅ |
| **自己动手操作工具** | ❌ 只输出文本 | ✅ 有云电脑，登录你的账号去点 |
| **记住上次怎么做** | ❌ 每次靠提示词重新喂 | ✅ routine 复用 |
| **后台常驻运行** | ❌ 你手动触发 | ✅ 定时自己跑 |

**结论：你的系统在"岗位定义和链路编排"上已经到位，缺的是"能自己动手 + 会记 routine + 常驻运行"。**

这不是你现在的短板（那需要云端和服务器，你现在单人阶段也用不上），但它是**你未来从"卖提示词"升级到"卖能自己干活的智能体"的分界线**。

## 四、我已经把缺口做成可执行的东西

### 1️⃣ `run.py funnel` —— 成交漏斗体检

新增命令。读系统里的**真实数据**（发布日志、SKU 库存、禁区条数、货架页状态、选题池），输出一条五段漏斗：

```
货 → 引流 → 试 → 成交 → 留
```

每一段给完成度、最大缺口、**以及现在就能执行的一条命令**。数据读不到就标「未开始」，不编。

用法：
```bash
python run.py funnel              # 看漏斗
python run.py funnel --export     # 导出体检报告
```

### 2️⃣ `run.py demo` —— 结果前置演示器

**这是视频②「成交升维」的直接落地。**

给潜在客户一段**他自己的文案**，30 秒内生成：
- 违规 / AI味 / 错误 三合一体检报告
- 逐条改写示范

他看见自己的文案有问题，才会愿意付钱解决。**这是免费成交入口**——对应智向未来的"可试问"，也是陈灏说的"让用户先看见结果"。

用法：
```bash
python run.py demo --file 客户的文案.md
python run.py demo --text "直接粘贴一段文案"
```

产物自动打包成「演示包」（体检报告 + 改写示范 + 合并版），可以直接发给客户。
